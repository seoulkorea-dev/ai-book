프롬프트 인젝션

프롬프트 인젝션은 입력 데이터 안에 숨긴 문장이 AI의 원래 지시를 변경하는 공격입니다. OWASP는 「Top 10 for LLM Applications」 2025년 판에서 첫 번째 위험 항목(LLM01)으로 분류했습니다.

완전히 막기 어려운 이유

SQL 인젝션은 명령과 데이터를 구조적으로 분리해 막을 수 있습니다. LLM에서는 지시와 데이터가 모두 자연어로 같은 입력에 들어가므로 구조적으로 분리할 방법이 아직 없습니다. 그래서 여러 겹의 방어로 피해를 줄입니다.

AI 에이전트 보안

에이전트는 파일, 메일, 브라우저, 외부 서비스를 직접 조작하므로 잘못된 판단이 곧 실제 작업으로 이어집니다. 단순 대화에서 공격의 피해는 잘못된 답변이지만, 에이전트에서는 잘못된 행동입니다.
