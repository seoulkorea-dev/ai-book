추론

추론 모델과 추론 유도 방법을 정리합니다.

추론 모델 사용법

추론 모델은 답하기 전에 내부 추론 과정을 거칩니다. OpenAI는 추론 모델 안내에서 지시를 짧고 직접적으로 쓰고, 단계별로 생각하라는 지시를 따로 넣지 않도록 안내했습니다.

최근 모델은 한 모델 안에서 추론량을 조절합니다. Anthropic은 Claude Opus 4.6에서 모델이 작업 난이도에 따라 추론량을 스스로 정하는 적응형 추론을 도입했고, Claude Opus 4.7부터는 적응형 추론만 지원합니다. 추론량은 노력 수준(effort) 설정으로 조절합니다. 모델을 고르는 일과 함께 추론 강도를 정합니다.

추론 유도

일반 모델에서는 추론 단계를 지정해 줍니다. 예: "조건을 나열하고, 조건별로 확인하고, 마지막 줄에 결론을 적으십시오."

간접 추론

직접 증명하기 어려운 명제를 대우나 모순을 이용해 확인하도록 지시하는 방법입니다. 예: "결론이 거짓이라고 가정하고 모순이 생기는지 확인하십시오."

추론 결과 검증

  • 중간 단계의 계산을 따로 확인합니다.
  • 같은 문제를 다른 방법으로 다시 풀게 해 결과를 비교합니다.
  • 추론 과정이 그럴듯해도 결론은 독립적으로 검증합니다.
