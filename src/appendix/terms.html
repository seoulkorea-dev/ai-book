Appendix 2 용어 풀이

본문에서 정의한 용어를 본문과 같은 표기와 정의로 정리했습니다.

찾는 방법: 한국어 용어는 가나다순, 영어로 시작하는 용어는 알파벳순이고, 항목 끝의 장은 그 용어를 처음 정의한 장입니다.

한국어 용어

가명처리
추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보의 일부를 삭제하거나 대체하는 처리입니다. 「개인정보 보호법」의 용어입니다. (Chapter 6)
가중치(Weight)
모델이 학습으로 정하는 내부 수치입니다. 오픈 가중치 모델은 이 수치를 담은 파일을 공개합니다. (Chapter 6)
간접 인젝션
AI가 읽는 웹 페이지, 문서, 메일 안에 지시를 숨겨 두는 프롬프트 인젝션입니다. (Chapter 8)
검색 색인
질문과 관련된 문서 조각을 검색하도록 미리 구축하는 자료입니다. 구축 과정에는 임베딩 생성과 벡터 저장소 구성이 포함됩니다. (Chapter 6)
검색 증강 생성(Retrieval-augmented Generation, RAG)
답을 만들기 전에 관련 문서를 검색해 근거로 함께 제공하는 방식입니다. 검색은 모델 바깥의 검색 시스템이 맡고, 모델은 받은 조각을 근거로 답을 작성합니다. (Chapter 4)
고유식별정보
주민등록번호처럼 법령에 따라 한 사람에게 부여되어 그 사람을 구별하는 번호입니다. 개인정보 가운데 입력 기준이 가장 엄격합니다. (Chapter 6)
공정 이용(Fair Use)
이용의 목적과 성격, 저작물의 성격, 이용한 분량, 시장에 미치는 영향을 따져 권리자의 허락 없는 이용을 허용하는 미국 저작권법의 원칙입니다. (Chapter 8)
과도한 권한(Excessive Agency)
에이전트가 필요 이상의 작업 권한을 갖는 보안 위협입니다. (Chapter 8)
과의존
AI 없이는 글 작성, 결과 확인, 판단을 하기 어려울 만큼 AI에 기대는 상태입니다. (Chapter 8)
교차 검증(Cross-checking)
결과에 담긴 사실을 원문을 포함한 서로 독립된 출처 두 곳 이상과 대조해 같은 내용인지 확인하는 일입니다. (Chapter 4)
구분 기호
입력 자료의 시작과 끝을 표시해 지시와 자료를 나누는 기호입니다. 따옴표 세 개, 제목 줄, XML 태그가 있습니다. (Chapter 2)
구조화된 단계별 추론
계산과 판단이 섞인 문제에서 거칠 단계를 직접 지정하는 단계별 추론입니다. (Chapter 3)
구조화된 피드백
현상, 기준, 요청의 세 부분으로 나눠 작성한 피드백입니다. (Chapter 4)
금지 관행
EU 인공지능법에서 허용 불가 등급에 해당해 금지하는 AI 사용입니다. (Chapter 8)
기반 역량
활용 역량의 바탕이 되는, AI 사용에 한정되지 않는 일반 역량입니다. 비판적 사고, 창의성, 소통과 협업, 메타인지, 학습 민첩성의 다섯 가지입니다. (Chapter 7)
내재적 환각
주어진 입력 자료와 모순되는 내용을 생성하는 환각입니다. 입력 자료와 대조하면 찾을 수 있습니다. (Chapter 4)
단계별 추론(Chain of Thought, CoT)
답을 바로 내지 않고 중간 과정을 먼저 작성하게 하는 방법입니다. (Chapter 3)
대규모 언어 모델(Large Language Model, LLM)
대량의 텍스트로 학습해 다음에 올 토큰을 확률로 선택하며 문장을 이어 가는 생성형 모델입니다. (Chapter 1)
대리 실행
AI가 검색, 코드 실행, 파일 처리 같은 도구를 직접 사용해 작업을 수행하는 방식입니다. (Chapter 6)
대표 입력 모음
프롬프트가 실제로 처리할 자료 가운데 길이, 형식, 내용이 서로 다른 입력(대표 입력)을 선택해 묶은 것입니다. (Chapter 4)
데이터 반출 가능 여부
입력할 데이터를 외부로 보낼 수 있는지의 판단입니다. 판단 기준은 입력 데이터 분류와 조직의 사용 정책입니다. (Chapter 7)
도구 설명 오염
연결한 도구의 설명문에 악성 지시를 숨기는 보안 위협입니다. (Chapter 8)
독립된 출처
서로 인용하지 않고 같은 원자료에서 나오지 않은 출처입니다. (Chapter 4)
딥 러닝(Deep Learning)
계산 층을 여러 겹 쌓은 모델이 데이터의 특징을 스스로 찾는 머신 러닝 방법입니다. (Chapter 1)
딥페이크(Deepfake)
실존 인물이나 사물을 실제처럼 보이게 합성한 이미지, 음성, 영상입니다. (Chapter 8)
마일스톤
프로젝트 중간에 주요 산출물의 완료를 확인하는 시점입니다. (Chapter 6)
머신 러닝(Machine Learning)
데이터에서 찾은 패턴으로 예측하고 분류하는 방법입니다. (Chapter 1)
멀티모달(Multimodal) 모델
여러 모달리티를 함께 처리하는 모델입니다. (Chapter 1)
메모리(Memory)
대화형 제품이 이전 대화의 정보를 저장해 다음 대화에 반영하는 기능입니다. (Chapter 4)
메모리 오염
AI의 메모리나 검색 문서에 악성 내용을 심는 보안 위협입니다. (Chapter 8)
메타인지
자기가 무엇을 알고 모르는지 아는 능력입니다. AI 결과를 스스로 확인할 수 있는 분야를 가리는 기준이 됩니다. (Chapter 7)
명확성 원칙
모호한 표현을 분량, 수준, 범위 같은 기준으로 구체화하는 원칙입니다. (Chapter 2)
모달리티(Modality)
텍스트, 이미지, 음성처럼 데이터가 표현되는 형태입니다. (Chapter 1)
모름 허용(Abstention)
근거가 부족할 때 추측하지 않고 모른다고 답하도록 허용하는 지시입니다. (Chapter 4)
미세 조정(Fine-tuning)
학습을 마친 모델을 특정 데이터로 추가 학습시키는 작업입니다. (Chapter 7)
배포자
EU 인공지능법에서 AI 시스템을 자기 권한 아래 사용하는 자입니다. (Chapter 8)
범용 AI 모델
여러 용도에 사용할 수 있는 AI 모델입니다. EU 인공지능법은 위험 등급과 별도로 그 제공자에게 의무를 부과합니다. (Chapter 8)
범용 대화형 제품
글쓰기, 요약, 분석, 질의응답처럼 특정 분야에 한정되지 않는 작업을 대화로 처리하는 제품입니다. (Chapter 7)
벡터 저장소(Vector Store)
임베딩을 저장하고 질문의 임베딩과 가까운 항목을 찾는 저장소입니다. (Chapter 6)
병렬 탐색
사람이 서로 다른 초안을 여러 개 받아 비교하고 선택하는 방법입니다. (Chapter 4)
사람 피드백 기반 강화 학습(RLHF)
사람이 여러 답변을 비교해 정한 순위로 답변의 점수를 계산하는 모델을 먼저 학습하고, 언어 모델이 그 점수가 높은 답변을 내도록 추가 학습하는 방법입니다. Reinforcement Learning from Human Feedback의 약자입니다. (Chapter 1)
사람의 검토(Human in the Loop)
AI 결과가 효력을 갖기 전에 사람이 확인하고 승인하는 절차입니다. (Chapter 6)
사용 사실 표기
사용자가 기관 규정에 따라 사용한 도구와 범위를 밝히는 일입니다. (Chapter 8)
사용자 프롬프트
사용자가 매번 입력하는 질문과 지시입니다. 프롬프트 구성 요소로 나눠 적습니다. (Chapter 2)
사전 학습(Pre-training)
웹 문서, 책, 코드 같은 대량 텍스트로 다음 토큰을 예측하는 기본 모델을 만드는 첫 학습 단계입니다. 이 단계에서 언어와 지식의 기본 능력이 만들어집니다. (Chapter 1)
생성 설정
모델이 다음 토큰을 선택하는 방식을 조절하는 값입니다. temperature, top_p, 최대 토큰 수가 있습니다. (Chapter 3)
생성형 AI(Generative AI)
학습한 패턴을 바탕으로 새로운 텍스트, 이미지, 음성, 코드를 만드는 AI입니다. (Chapter 1)
섀도 AI(Shadow AI)
조직이 파악하지 못한 채 사용되는 AI 도구와 에이전트입니다. 직원이 정책 없이 개인 계정으로 AI 도구를 사용하는 경우가 대표적입니다. (Chapter 8)
서지 정보
제목, 저자, 연도, 학술지처럼 문헌을 특정하는 정보입니다. (Chapter 5)
선호 학습(Preference Learning)
사람이나 AI가 비교 평가한 답변으로 모델이 선호되는 답변을 내도록 추가 학습하는 단계입니다. 사람 피드백 기반 강화 학습과 Constitutional AI가 그 방법의 예입니다. (Chapter 1)
소크라테스식 질문
AI가 정답을 알려 주는 대신 질문하고, 사용자가 답하면서 스스로 이해를 점검하는 방법입니다. (Chapter 5)
시스템 프롬프트(System Prompt)
제품이 대화 앞에 미리 포함하는 기본 지시입니다. 제품 개발자가 작성하며, 대화 전체에 적용됩니다. (Chapter 1)
어시스턴트 메시지
다음 답변의 맥락으로 들어가는 모델의 이전 답변입니다. (Chapter 2)
에이전트(Agent)
목표를 받아 도구 호출, 결과 확인, 다음 행동 결정을 반복하는 AI 시스템입니다. (Chapter 3)
역할 부여(Role Prompting)
모델에게 특정 직무나 관점을 지정하는 방법입니다. 역할은 설명의 관점을 정할 뿐, 모델에게 없는 전문 지식을 더하지 않습니다. (Chapter 2)
연동 규격
AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 규격입니다. MCP가 그 예입니다. (Chapter 7)
오픈 가중치 모델(Open-weight Model)
학습을 마친 모델의 가중치 파일을 공개해 누구나 내려받아 자기 컴퓨터나 서버에서 실행할 수 있게 한 모델입니다. (Chapter 7)
외재적 환각
입력으로 확인할 수 없는 내용을 생성하는 환각입니다. 외부 원문을 찾아야 확인됩니다. (Chapter 4)
워크플로
코드로 정한 순서대로 실행하는 방식입니다. 에이전트와 달리 실행 과정을 모델이 결정하지 않습니다. (Chapter 8)
원문 대조
결과의 사실을 그 사실이 나온 문서와 비교하는 일입니다. (Chapter 4)
인공지능
사람의 지적 작업을 컴퓨터로 수행하는 기술 전체입니다. (Chapter 1)
임계 경로
여유 기간 없이 이어져, 하나가 늦어지면 프로젝트 종료가 함께 늦어지는 작업의 연결입니다. (Chapter 6)
임베딩(Embedding)
텍스트의 의미를 숫자 벡터로 변환한 표현입니다. 의미가 가까운 문장은 서로 가까운 벡터가 됩니다. (Chapter 6)
입력 데이터 분류
데이터를 공개 정보, 내부 정보, 개인정보, 고유식별정보, 영업 비밀의 다섯 유형으로 나누고 유형마다 입력할 수 있는 환경을 정한 기준입니다. (Chapter 6)
자기 검토 요청
결과를 받은 뒤 모델에게 그 결과를 다시 점검하게 하는 방법입니다. 점검 결과는 사람이 확인할 목록으로 사용합니다. (Chapter 3)
자기 평가표
역량 10개마다 현재 행동에 가장 가까운 단계를 선택하는 평가 기준표입니다. 아는 내용보다 실제로 하는 행동을 기준으로 단계를 선택합니다. (Chapter 7)
자동화 편향(Automation Bias)
자동화 시스템의 결과를 자기 판단이나 다른 정보보다 더 신뢰하는 경향입니다. 학습 데이터의 편향과는 다른 개념입니다. (Chapter 4)
자율성 단계
대리 실행을 맡은 에이전트가 사람의 확인 없이 실행하는 범위를 정한 구분입니다. 제안, 승인 실행, 범위 자율, 자율 실행의 네 단계입니다. (Chapter 8)
작업 분해
프로젝트를 담당자와 기간을 정할 수 있는 크기의 작업으로 나누는 일입니다. (Chapter 6)
적응형 추론(Adaptive Thinking)
모델이 작업 난이도에 따라 추론량을 정하고, 사용자는 노력 수준(effort) 설정으로 그 정도를 조절하는 방식입니다. (Chapter 3)
점검 영역
결과물을 사용하기 전에 점검할 편향, 개인정보, 권리, 투명성, 책임, 환경의 여섯 영역입니다. (Chapter 8)
제품 비교 점검표
선택 기준을 적용해 대화형 제품을 비교하는 기록 양식입니다. 확인한 값과 함께 확인 위치와 확인 날짜를 기록합니다. (Chapter 7)
제품형 서비스
제공 회사의 서버에서 모델을 실행하고, 사용자는 화면이나 API로 이용하는 방식입니다. 범용 대화형 제품과 특화 도구가 이 방식입니다. (Chapter 7)
지시 학습(Instruction Tuning)
지시와 모범 답변의 쌍으로 지시를 따르는 모델을 만드는 학습 단계입니다. (Chapter 1)
지식 기준일(Knowledge Cutoff)
학습 데이터에 포함된 정보의 마지막 시점입니다. (Chapter 1)
직접 인젝션
사용자가 입력창에 "이전 지시를 무시하라" 같은 문장을 입력하는 프롬프트 인젝션입니다. (Chapter 8)
최대 토큰 수
한 번에 생성할 답변 길이의 토큰 상한입니다. 답변이 이 값에 이르면 문장 중간이라도 생성이 멈춥니다. (Chapter 3)
추론 모델(Reasoning Model)
답변을 생성하기 전에 내부적으로 추론하는 모델입니다. (Chapter 3)
출력 신뢰
검증하지 않은 AI 결과를 시스템에 그대로 반영하는 보안 위협입니다. (Chapter 8)
컨텍스트 윈도(Context Window)
모델이 한 번에 처리하는 토큰의 최대 개수입니다. (Chapter 1)
코드 실행 기능
모델이 작성한 코드를 제품 안의 실행 환경에서 실행해 결과를 답에 반영하는 기능입니다. (Chapter 6)
탈옥
모델의 안전 정책을 우회하는 요청입니다. (Chapter 8)
토크나이저(Tokenizer)
텍스트를 토큰으로 분할하는 도구입니다. 토크나이저는 모델마다 다릅니다. (Chapter 1)
토큰(Token)
모델이 처리하는 텍스트 단위입니다. 토큰 하나는 단어 전체이거나 단어의 일부입니다. (Chapter 1)
튜터링
AI가 답 대신 힌트와 질문을 주고, 사용자가 스스로 문제를 풀게 하는 활용 방식입니다. (Chapter 5)
트랜스포머(Transformer)
다음 토큰의 확률을 계산하는 모델 구조입니다. 입력의 각 토큰이 다른 토큰과 어떤 관계인지 따져 다음 토큰의 확률에 반영합니다. (Chapter 1)
특화 도구
특정 작업에 맞춰 설계된 도구입니다. 검색 특화, 업무 도구 내장, 코딩, 이미지 생성, 영상 생성, 문서 기반 조사의 여섯 유형이 있습니다. (Chapter 7)
판별형 모델(Discriminative Model)
입력을 정해진 분류 가운데 하나로 판단하는 모델입니다. 생성형 모델은 입력에 맞는 새로운 결과물을 만듭니다. (Chapter 1)
편향(Bias)
학습 데이터의 불균형이 결과에 반영되어 특정 집단에 불공정한 결과를 내는 현상입니다. (Chapter 1)
표절
다른 사람의 글이나 생각을 출처를 밝히지 않고 자기 것처럼 사용하는 행위입니다. (Chapter 8)
프롬프트(Prompt)
모델에 주는 입력 전체입니다. 시스템 프롬프트와 이전 대화도 프롬프트에 포함됩니다. (Chapter 1)
프롬프트 개선 요청
같은 답을 다시 요청하지 않고, 모델에게 프롬프트 자체를 검토하게 하는 방법입니다. 누락된 구성 요소와 수정한 프롬프트를 받습니다. (Chapter 3)
프롬프트 구성 요소
요청에 담을 정보를 목적, 역할, 맥락, 출력 형식, 제약 조건으로 나눈 것입니다. 사용자는 필요한 요소만 이 순서로 적습니다. (Chapter 2)
프롬프트 유출
시스템 프롬프트의 내용을 빼내는 보안 위협입니다. (Chapter 8)
프롬프트 인젝션(Prompt Injection)
입력에 담은 문장으로 AI가 원래 지시와 다른 행동을 하게 만드는 공격입니다. (Chapter 2)
프롬프트 체이닝(Prompt Chaining)
작업을 여러 프롬프트로 나누고, 앞 단계의 결과를 다음 단계의 입력으로 사용하는 방법입니다. (Chapter 3)
확인 위치
값을 확인한 공식 안내나 개발 문서의 URL입니다. (Chapter 7)
환각(Hallucination)
사실이 아니거나 입력과 맞지 않는 내용을 사실처럼 생성하는 현상입니다. (Chapter 1)
환각 의심 신호
AI 결과 가운데 환각일 가능성이 높은 부분입니다. (Chapter 4)
활용 역량
AI 사용에 직접 필요한 역량입니다. 문제 정의, 지시 작성, 검증, 도메인 지식, 윤리 판단의 다섯 가지입니다. (Chapter 7)
후보 문헌
AI가 제시한 문헌 가운데 아직 확인하지 않은 문헌입니다. 존재, 서지 정보, 인용 문장을 차례로 원문에서 확인한 뒤에만 인용합니다. (Chapter 5)

영어 약어와 용어

AI 리터러시 조항
AI 시스템의 제공자와 배포자가 직원이 AI를 이해하고 다룰 수 있도록 조치하게 한 EU 인공지능법의 조항입니다. (Chapter 8)
AI 생성물 표시 의무
결과물이 AI로 생성되었다는 사실을 밝혀야 하는 의무입니다. 의무의 범위는 결과물의 종류, 실제와 구분하기 어려운 정도, 제공 주체와 유통 방식에 따라 다릅니다. (Chapter 6)
AI 탐지 도구
글이 AI로 작성되었는지를 판정하는 도구입니다. 사람이 작성한 글을 AI가 작성한 글로 판정하는 오류가 있습니다. (Chapter 5)
AI에 맡기는 방식
작업 하나를 AI에 맡길 때 사람이 관여하는 정도에 따른 구분입니다. 자동화, 증강, 대리 실행의 세 가지입니다. (Chapter 6)
API(Application Programming Interface)
프로그램이 다른 프로그램의 기능을 호출하는 통로입니다. 프로그램에서 모델을 호출하면 사용량에 따라 요금이 발생합니다. (Chapter 3)
Constitutional AI
AI가 원칙 목록을 기준으로 자기 답변을 평가하고 수정한 뒤, 그 수정한 답변으로 모델을 학습하는 방법입니다. Anthropic이 2022년 12월 발표했습니다. (Chapter 1)
DOI(Digital Object Identifier)
학술 자료의 고유 식별 번호입니다. 서지 정보를 대조할 때 사용합니다. (Chapter 5)
Few-shot
입력과 출력의 예시 몇 개를 프롬프트에 포함해 작업 방식을 보여 주는 기법입니다. (Chapter 3)
GPT(Generative Pre-trained Transformer)
OpenAI의 모델 계열 이름입니다. Generative Pre-trained Transformer의 약자입니다. (Chapter 1)
JSON
항목 이름과 값을 짝지어 적는 데이터 형식입니다. (Chapter 2)
MCP(Model Context Protocol)
AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 연동 규격입니다. Anthropic이 2024년 11월 공개했습니다. (Chapter 7)
MCP 서버
문서 저장소, 일정, 업무 도구 같은 외부 시스템의 데이터와 기능을 MCP 방식으로 제공하는 프로그램입니다. (Chapter 7)
ReAct(Reasoning and Acting)
추론과 행동(검색, 계산 같은 도구 사용)을 번갈아 수행하는 방식입니다. 에이전트의 반복도 같은 흐름입니다. (Chapter 3)
Self-consistency
같은 질문을 여러 번 추론하게 해 가장 많이 나온 답을 채택하는 기법입니다. (Chapter 3)
temperature
답변의 다양성을 조절하는 설정입니다. 낮으면 예측 가능한 표현을, 높으면 다양한 표현을 선택할 가능성이 커집니다. (Chapter 3)
top_k
확률 상위 k개 토큰 안에서만 다음 토큰을 선택하게 하는 설정입니다. (Chapter 3)
top_p
누적 확률이 지정한 값에 이를 때까지의 상위 토큰 안에서만 다음 토큰을 선택하게 하는 설정입니다. (Chapter 3)
Tree of Thoughts
여러 풀이 갈래를 만들어 평가하며 나아가는 기법입니다. (Chapter 3)
XML 태그
<문의>…</문의>처럼 여는 태그와 닫는 태그 사이에 자료를 두는 구분 기호입니다. (Chapter 2)
Zero-shot
예시 없이 지시만 주는 기본 방식입니다. (Chapter 3)
Zero-shot CoT
Zero-shot에 단계별로 생각하라는 지시 한 줄만 더하는 기법입니다. (Chapter 3)
