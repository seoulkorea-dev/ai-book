1부 이해

2장 주요 도구와 생태계

생성형 AI 도구는 모델, 제품, API, 연동 계층으로 구성합니다.

  • 도구 비교는 회사가 아니라 제품 단위로 합니다.
  • 같은 제품도 요금제와 계정 유형에 따라 기능과 데이터 처리 정책이 다릅니다.
  • 도구 선택 기준은 작업 목적, 데이터 정책, 연동 범위입니다.

생태계 계층

대화형 제품

제품 기능과 모델 버전은 자주 바뀝니다. 이 책은 기능 목록 대신 확인 방법을 안내합니다. 제품별 현재 기능은 표 2-2의 공식 안내에서 확인합니다.

연동 규격 MCP

MCP(Model Context Protocol)는 AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 규격입니다. A Anthropic은 2024년 11월 MCP를 공개했습니다. MCP 서버를 연결하면 AI 제품이 문서 저장소, 일정, 업무 도구의 데이터를 읽거나 작업을 수행합니다.
