1부 생성형 AI의 원리와 도구

2장 주요 도구와 선택 기준

생성형 AI 생태계는 모델, 제품, API, 연동, 에이전트의 5계층으로 구성됩니다.

  • 도구 비교는 회사가 아니라 제품 단위로 합니다.
  • 같은 제품도 요금제와 계정 유형에 따라 기능과 데이터 처리 정책이 다릅니다.
  • 도구 선택 기준은 작업 목적, 데이터 정책, 연동 범위입니다.

생태계 5계층

범용 대화형 제품

세 제품은 공통으로 대화, 파일 첨부, 이미지 이해, 웹 검색, 대화 묶음(프로젝트) 관리 기능을 제공합니다. 구체적인 기능 이름, 모델 버전, 요금제는 자주 바뀝니다. 이 책은 기능 목록 대신 확인 방법을 안내하며, 현재 기능은 표 2-2의 공식 안내에서 확인합니다.

특화 도구

범용 제품 외에 특정 작업에 맞춘 도구가 있습니다. 표 2-4는 유형별 대표 사례입니다. 사례는 처음 공개된 순서가 아니라 널리 쓰이는 제품 위주로 골랐습니다.

오픈 가중치 모델

오픈 가중치 모델은 학습된 모델 파일을 공개해 누구나 내려받아 자기 컴퓨터나 서버에서 실행할 수 있는 모델입니다. 기업 Meta의 Llama 계열, 기업 Mistral AI의 모델, 기업 Alibaba의 Qwen 계열, 기업 OpenAI의 gpt-oss 등이 있습니다.

오픈 가중치 모델도 라이선스마다 상업적 이용 조건이 다릅니다. 도입 전에 모델 배포 페이지의 라이선스 원문을 확인합니다.

연동 규격 MCP

MCP(Model Context Protocol)는 AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 규격입니다. 기업 Anthropic은 2024년 11월 MCP를 공개했습니다. MCP 서버를 연결하면 AI 제품이 문서 저장소, 일정, 업무 도구의 데이터를 읽거나 작업을 수행할 수 있습니다.

버전 주석 (2026년 9월)

기업 Anthropic은 2025년 12월 9일 MCP를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기부했습니다. ChatGPT, Gemini 등 다른 회사 제품도 MCP 연결을 지원합니다.

도구 선택 기준

도구는 그림 2-1의 순서로 고릅니다. 작업 목적으로 제품 유형을 먼저 정하고, 표 2-6의 공통 확인 항목으로 제품을 좁힙니다.

제품별 비교 기록은 부록 B의 점검표에 채웁니다.
