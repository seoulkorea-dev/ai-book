도구는 작업 목적, 데이터 정책, 연동 범위로 고르고, 자기 평가로 연습할 역량을 정합니다.

  • 같은 제품도 요금제와 계정 유형에 따라 기능과 데이터 처리 정책이 다릅니다.
  • 활용 역량과 기반 역량을 자기 평가표로 점검하고 연습 과제를 고릅니다.

생태계 5계층

범용 대화형 제품

세 제품은 공통으로 대화, 파일 첨부, 이미지 이해, 웹 검색, 대화 묶음(프로젝트) 관리 기능을 제공합니다. 구체적인 기능 이름, 모델 버전, 요금제는 자주 바뀝니다. 이 책은 기능 목록 대신 확인 방법을 안내하며, 현재 기능은 표 2-2의 공식 안내에서 확인합니다.

특화 도구

범용 제품 외에 특정 작업에 맞춘 도구가 있습니다. 표 2-4는 유형별 대표 사례입니다. 사례는 처음 공개된 순서가 아니라 널리 쓰이는 제품 위주로 골랐습니다.

오픈 가중치 모델

오픈 가중치 모델은 학습된 모델 파일을 공개해 누구나 내려받아 자기 컴퓨터나 서버에서 실행할 수 있는 모델입니다. Meta의 Llama 계열, Mistral AI의 모델, Alibaba의 Qwen 계열, OpenAI의 gpt-oss 등이 있습니다.

오픈 가중치 모델도 라이선스마다 상업적 이용 조건이 다릅니다. 도입 전에 모델 배포 페이지의 라이선스 원문을 확인합니다.

연동 규격 MCP

MCP(Model Context Protocol)는 AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 규격입니다. Anthropic은 2024년 11월 MCP를 공개했습니다. MCP 서버를 연결하면 AI 제품이 문서 저장소, 일정, 업무 도구의 데이터를 읽거나 작업을 수행할 수 있습니다.

버전 주석 (2026년 9월)

Anthropic은 2025년 12월 9일 MCP를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기부했습니다. ChatGPT, Gemini 등 다른 회사 제품도 MCP 연결을 지원합니다.

도구 선택 기준

도구는 그림 2-1의 순서로 고릅니다. 작업 목적으로 제품 유형을 먼저 정하고, 표 2-6의 공통 확인 항목으로 제품을 좁힙니다.

제품별 비교 기록은 부록 B의 점검표에 채웁니다.

도메인 지식의 역할

검증은 비교할 기준이 있어야 가능합니다. 회계 담당자는 AI가 작성한 분개의 오류를 찾고, 간호사는 AI가 요약한 투약 기록의 누락을 찾습니다. 자기 분야를 모르는 사용자는 문장이 자연스러운 오류를 통과시키기 쉽습니다. 머리말의 실험에서 AI의 능력 범위 밖의 과제에서 AI를 쓴 집단의 정답률이 낮았던 것도 같은 이유입니다.
