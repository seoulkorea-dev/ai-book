2부 원리

4장 고급 프롬프팅 기법

고급 프롬프팅 기법은 예시, 단계별 추론, 도구 사용, 작업 분할로 결과 품질을 높이는 방법입니다.

  • 예시를 주는 Few-shot은 형식과 기준을 전달합니다.
  • 단계별 추론(Chain of Thought)은 여러 단계의 계산과 논리 문제에 씁니다.
  • 큰 작업은 프롬프트 체이닝으로 나눕니다.

기법 요약

Few-shot

다음 문장의 감정을 긍정, 부정, 중립 중 하나로 분류하십시오.

문장: 배송이 하루 늦었지만 제품은 좋습니다. / 분류: 긍정
문장: 설명서와 다른 부품이 왔습니다. / 분류: 부정
문장: 주문은 월요일에 했습니다. / 분류: 중립
문장: 포장이 찢어져 있었고 환불도 거절당했습니다. / 분류:

예시는 분류 기준과 출력 형식을 함께 전달합니다. 예시가 한쪽 분류에 몰리면 결과도 그쪽으로 몰리므로 분류별로 고르게 넣습니다.

단계별 추론

단계별 추론은 답을 바로 내지 않고 중간 과정을 먼저 쓰게 하는 방법입니다. 여러 단계를 거치는 계산과 논리 문제에서 정확도가 올라갑니다.

추론 과정을 내부에서 수행하는 추론 모델에서는 사용 방법이 다릅니다. O OpenAI는 추론 모델 안내에서 추론 모델에는 단계별로 생각하라는 지시를 따로 넣지 않도록 안내했습니다.

ReAct

ReAct는 추론(Reasoning)과 행동(Acting)을 번갈아 수행하는 방식입니다. 모델이 필요한 정보를 판단하고, 검색 같은 도구를 호출하고, 결과를 보고 다음 행동을 정합니다. AI 에이전트의 기본 동작 방식입니다. 자세한 내용은 위키 에이전트에서 다룹니다.

프롬프트 체이닝

  1. 긴 보고서를 장별로 나눠 요약합니다.
  2. 장별 요약을 모아 핵심 주장을 뽑습니다.
  3. 핵심 주장으로 발표 자료 목차를 만듭니다.

단계를 나누면 단계별 결과를 확인하고, 틀린 단계만 다시 실행합니다.
