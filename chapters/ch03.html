2부 원리

3장 프롬프트 구조

프롬프트는 모델에게 주는 입력 전체이며, 지시, 맥락, 입력 데이터, 출력 형식으로 구성합니다.

  • 네 요소를 모두 적으면 결과의 편차가 줄어듭니다.
  • 구분 기호로 지시와 입력 데이터를 나눕니다.
  • 출력 형식을 예시로 보여 줍니다.

프롬프트의 네 요소

개선 전후 비교

개선 전

회의록 요약해 줘.

개선 후

다음 회의록을 요약하십시오.
읽는 사람은 회의에 참석하지 않은 팀장입니다.
결정 사항, 담당자, 기한을 표로 작성하고, 표 아래에 미결 사항을 불릿으로 적으십시오.
회의록에 없는 내용은 쓰지 마십시오.

<회의록>
(회의록 원문)
</회의록>

개선 후 프롬프트는 독자, 출력 형식, 금지 사항을 적었고, 입력 데이터를 태그로 구분했습니다.

구분 기호

지시와 입력 데이터가 섞이면 모델이 입력 데이터 속 문장을 지시로 처리합니다. 입력 데이터는 따옴표 세 개, 제목 줄, XML 태그 같은 구분 기호로 감쌉니다. A Anthropic은 프롬프트 작성 안내에서 XML 태그로 프롬프트의 부분을 나누도록 권장합니다.

역할 부여

역할 부여는 모델에게 특정 직무나 관점을 지정하는 방법입니다. 예를 들어 "당신은 신입 사원 교육 담당자입니다"라고 적으면 설명 수준과 용어 선택이 그 역할에 맞춰집니다. 역할만 적고 작업과 형식을 빠뜨리면 효과가 작으므로, 역할은 네 요소와 함께 씁니다.

출력 형식 지정

  • 표, 불릿, JSON 등 형식을 이름으로 지정합니다.
  • 분량은 문장 수나 글자 수로 지정합니다.
  • 형식이 복잡하면 빈 틀을 예시로 줍니다.
  • 금지 사항은 긍정 지시와 함께 적습니다. 예: "추측하지 마십시오. 원문에 없는 내용은 '확인 불가'로 적으십시오."
