3부 활용

6장 학습과 연구

학습과 연구에서 생성형 AI는 설명, 연습 문제, 요약, 자료 탐색을 돕고, 사실과 출처 확인은 사용자가 합니다.

  • AI 설명은 교재나 원문으로 확인합니다.
  • AI가 제시한 참고문헌은 원문을 열어 존재와 내용을 확인합니다.
  • 과제와 논문에 AI를 쓰기 전에 기관 정책을 확인합니다.

활용 영역

개념 설명 요청

광합성의 명반응과 암반응을 고등학교 생물 수준으로 설명하십시오.
각 반응의 장소, 입력, 출력을 표로 정리하고,
학생이 자주 혼동하는 개념 두 가지를 표 아래에 적으십시오.

수준, 형식, 분량을 지정하면 교재와 비교하기 쉬운 결과가 나옵니다.

참고문헌 확인

대화형 AI는 존재하지 않는 논문 제목, 저자, 쪽수를 만들어 냅니다. 참고문헌은 아래 순서로 확인합니다.

  1. 학술 검색 서비스에서 제목으로 검색해 존재를 확인합니다.
  2. DOI나 출판사 페이지에서 저자, 연도, 학술지를 대조합니다.
  3. 인용할 문장이 원문에 있는지 본문에서 확인합니다.
  4. 확인하지 못한 문헌은 쓰지 않습니다.

학술 윤리

3 Nature는 2023년 1월 사설에서 대규모 언어 모델을 논문 저자로 인정하지 않으며, 사용한 경우 방법 또는 감사의 글에 밝히도록 하는 원칙을 발표했습니다. 대학과 학회도 각자의 규정을 둡니다. 과제나 논문에 AI를 쓰기 전에 해당 기관의 규정을 확인하고, 사용 범위를 밝힙니다. 사례는 위키 사례연구에서 다룹니다.
