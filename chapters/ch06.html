Chapter 6 업무 위임, 기획서 초안, 창작

업무와 창작에서 생성형 AI는 초안, 정리, 분석, 아이디어를 맡고, 사람은 최종 판단과 발송을 맡습니다. 결과가 조직 밖으로 나가거나 다른 사람에게 영향을 주는 순간의 책임은 사람에게 있기 때문입니다.

  • 회사 정책이 허용한 도구와 계정만 사용합니다.
  • AI에 맡기는 방식(자동화, 증강, 대리)에 따라 검토 수준을 정합니다.
  • 창작은 구조를 사람이 정하고, AI에게는 부분 초안을 요청합니다.

업무 영역별 활용

AI는 대부분의 업무 영역에서 초안과 정리를 맡을 수 있지만, 영역마다 사람이 반드시 확인할 지점이 다릅니다. 문서는 사실과 어조를, 데이터 분석은 계산 결과를, 인사 업무는 차별 표현을 확인합니다. 표 6-1은 업무 영역 9개의 작업 예제와 사람의 검토 지점입니다.

AI에 맡기는 방식

AI에 맡기는 방식은 작업 하나를 AI에 맡길 때 사람이 관여하는 정도에 따른 구분입니다. Anthropic은 2025년 2월 「Anthropic Economic Index」 보고서에서 Claude 대화를 분석해, 작업 전체를 맡기는 자동화와 사람과 함께 작업하는 증강의 비율을 발표했습니다. 이 책은 여기에 AI가 도구를 직접 실행하는 대리 방식을 추가해 세 가지로 구분합니다. 표 6-2는 방식별 사람의 역할과 검토 수준입니다.

익숙하지 않은 분야의 작업은 증강 방식으로 시작하고, 기준표로 반복 검증한 뒤에 자동화로 전환합니다. 대리 방식의 통제는 Chapter 8에서 다룹니다.

도입 단계

조직의 AI 도입은 개인 사용에서 에이전트 운영까지 네 단계로 확대됩니다. 맡기는 방식이 작업 하나의 구분이라면, 도입 단계는 조직 차원의 구분입니다. 단계가 올라갈수록 AI가 사람의 확인 없이 수행하는 작업이 늘어나므로, 단계마다 필요한 통제도 함께 늘려야 합니다(표 6-3).

조직 정책은 Chapter 8에서, 에이전트 도입 절차는 위키 거버넌스에서 다룹니다.

입력 데이터 관리

업무에 AI를 사용할 때 가장 먼저 정할 것은 어떤 데이터를 입력할 수 있는지입니다. 입력한 데이터는 제품의 데이터 처리 정책에 따라 외부 서버에 저장되거나 학습에 사용될 수 있기 때문입니다. 표 6-4는 데이터를 다섯 유형으로 나누고 유형별 입력 기준을 정리합니다.

개인정보를 입력해야 하는 경우에는 가명처리를 거칩니다. 가명처리는 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보의 일부를 삭제하거나 대체하는 처리입니다(「개인정보 보호법」 제2조). 예를 들어 고객 이름은 '고객 A'로 대체하고 연락처는 삭제한 뒤 입력합니다. 또한 개인 계정과 조직 계정은 데이터 처리 조건이 다르므로, 업무 데이터는 조직이 계약한 계정에서 처리합니다.

데이터 분석

데이터 분석은 코드 실행 기능이 있는 제품에서 수행합니다. 기능이 없는 대화에서 모델이 직접 계산한 수치에는 오류가 생길 수 있기 때문입니다(Chapter 1). 코드 실행 기능이 있으면 모델이 표 파일을 읽고 코드를 실행해 계산, 차트, 요약을 만듭니다. 아래 예제는 계산을 코드로 수행하게 하고, 확인할 수 없는 원인은 '추정'으로 표시하게 합니다.

첨부한 월별 매출 파일을 분석하십시오.
1. 코드를 실행해 월별 합계와 전월 대비 증감률을 표로 만드십시오.
2. 증감률이 가장 큰 달 두 개를 적으십시오.
3. 원인은 파일에서 확인되는 내용만 쓰고, 추정은 '추정'이라고 표시하십시오.
4. 사용한 코드를 마지막에 보여 주십시오.

결과를 받은 뒤에는 합계 몇 개를 원본 파일에서 직접 계산해 대조합니다. 표 계산 프로그램의 수식을 요청한 경우에도 작은 표에 먼저 적용해 결과를 확인합니다.

기획서 초안과 전략 분석

기획서 초안은 구조를 먼저 정하고 절별로 작성하게 합니다. 처음부터 전체를 요청하면 일반적인 내용으로 채워지기 때문입니다. 목차와 절별 핵심 문장을 먼저 받아 사람이 확정한 뒤, 절마다 근거 자료를 함께 입력해 초안을 요청합니다.

기획서에 포함하는 SWOT 분석처럼 틀이 정해진 분석은 AI가 빠르게 초안을 만듭니다. 다만 결과의 질은 입력한 자료에 달려 있으므로, 회사 내부 현황과 시장 자료를 함께 제공하고 항목마다 근거 자료를 표시하게 합니다.

다음 자료를 근거로 [사업]의 SWOT 분석표를 작성하십시오.
강점과 약점은 내부 요인, 기회와 위협은 외부 요인만 쓰십시오.
각 항목 옆에 근거가 된 자료 번호를 적고, 자료에 없는 항목은 쓰지 마십시오.
표 아래에 강점으로 기회를 살리는 전략 두 가지를 제안하십시오.

<자료>
1. [내부 현황]
2. [시장 자료]
</자료>

프로젝트 관리

프로젝트 관리에서 AI는 작업 분해, 일정표, 위험 목록, 주간 보고처럼 구조가 정해진 문서를 만듭니다. 문서의 형식은 AI가 갖추지만, 일정과 위험이 실제 조직 사정에 맞는지는 사람이 판단해야 합니다. 표 6-5는 작업별 요청 예제와 확인할 점입니다.

업무 소통

업무 소통 문서는 받는 사람과 목적이 분명하므로, 전달할 사실을 항목으로 입력하고 문체와 형식을 지정하면 수정할 부분이 적은 초안을 얻습니다.

메일 초안

메일은 사실 항목, 요청 사항, 문체를 함께 입력합니다. 아래 예제는 납기 지연 안내에 필요한 사실을 항목으로 제공하고, 사과 문장의 분량까지 지정합니다.

다음 정보로 거래처에 보낼 납기 지연 안내 메일을 작성하십시오.
- 지연 품목: 산업용 필터 A형
- 기존 납기: 10월 7일, 변경 납기: 10월 14일
- 원인: 원자재 입고 지연
- 요청: 변경 납기 수락 여부 회신
문체는 정중한 업무용으로, 사과는 한 문장만 넣으십시오. 제목도 작성하십시오.

발표 준비

발표 자료는 목차와 슬라이드별 핵심 문장을 먼저 받고, 사람이 순서와 강조점을 정한 뒤 문장을 다듬게 합니다. 청중이 할 질문과 답변 초안도 함께 요청할 수 있습니다.

인사 업무의 한계

인사 업무에서 AI가 맡을 수 있는 범위는 문서 작성까지입니다. 채용 공고와 교육 자료 초안에는 AI를 사용할 수 있지만, 지원자 평가, 승진, 해고처럼 사람에게 영향을 주는 판단에는 AI 결과를 그대로 사용하지 않습니다. 학습 데이터의 편향이 판단에 반영될 수 있기 때문이며, 이유와 사례는 Chapter 8에서 다룹니다.

생성 유형

창작에서 AI가 생성하는 결과물은 글, 이미지, 음성, 음악, 영상의 다섯 유형입니다. 유형마다 권리와 표시 의무의 쟁점이 다르므로, 결과물을 사용하기 전에 확인할 사항도 다릅니다(표 6-6).

창작 작업 절차

창작 작업은 AI가 후보를 만들고 사람이 선택과 점검을 맡는 구조로 진행합니다.

  1. 목적과 대상 독자를 정합니다.
  2. AI로 아이디어와 초안을 여러 개 만듭니다.
  3. 사람이 선택하고 다시 작성합니다.
  4. 권리 침해 요소(실존 인물, 상표, 기존 작품)를 점검합니다.
  5. 도구 약관이나 게시 플랫폼이 요구하면 AI 생성 사실을 표시합니다.

이야기 구성

이야기 구성은 창작 작업 절차를 이야기에 적용한 것입니다. 사람이 구조를 정하고 AI에게 부분 작업을 맡깁니다. 구조를 정하지 않고 전체를 요청하면 결과를 통제하기 어렵기 때문입니다. 작업은 다음 순서로 진행합니다.

  1. 주제와 독자를 정합니다.
  2. 등장인물의 목표, 장애물, 변화를 표로 정리합니다.
  3. 시작, 갈등, 전환, 결말의 네 부분으로 줄거리를 정합니다.
  4. 부분별로 AI에게 장면 초안을 여러 개 요청하고 사람이 선택합니다.
  5. 문체를 통일하도록 전체를 다듬습니다.

아래 예제는 3단계의 구조를 조건으로 제시하고, 서로 다른 안 세 가지를 요청합니다.

다음 조건으로 3분 분량 브랜드 소개 영상의 이야기를 세 가지 안으로 제시하십시오.
주인공: 동네에서 20년째 빵집을 하는 제빵사
목표: 새로 이사 온 주민에게 가게를 알림
구조: 시작, 갈등, 전환, 결말을 각각 두 문장으로
각 안의 차이를 한 줄로 요약하십시오.

플랫폼별 콘텐츠

플랫폼을 맥락으로 적고 플랫폼별 조건을 지정하면 형식이 맞는 초안을 얻습니다. 같은 내용도 게시할 플랫폼에 따라 길이, 구조, 문체가 다르기 때문입니다. 표 6-7은 플랫폼별 형식과 요청 시 적을 조건입니다.

원고 하나를 여러 플랫폼용으로 변환할 때는 원고를 입력 자료로 제공하고, 사실은 그대로 두고 형식만 변환하도록 제약 조건을 둡니다.

이미지 프롬프트 구성

이미지 프롬프트는 주제, 구도, 스타일, 조명과 색, 비율, 제외 요소의 여섯 요소로 구성합니다(표 6-8). 결과물이 그림이므로 화면에 담길 요소를 하나씩 지정해야 하기 때문입니다.

표 6-8의 작성 예제를 순서대로 이으면 아래 프롬프트가 됩니다.

창가에 놓인 화분, 정면에서 가까이 본 구도, 화면 오른쪽에 배치.
평면 삽화 스타일, 오전 햇빛, 연한 초록과 베이지 색 조합.
16:9 비율. 글자, 로고, 사람 얼굴은 넣지 마십시오.

실존 작가의 이름으로 스타일을 지정하거나 상표와 캐릭터를 포함하면 도구 정책상 제한되거나 권리 분쟁이 생길 수 있습니다. 이런 요청을 제한하는 정책은 도구마다 다르므로 이용 약관을 확인합니다.
