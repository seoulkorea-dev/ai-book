Chapter 7 나에게 맞는 AI 도구 선택과 역량 진단

결과의 차이는 도구의 종류와 그 도구를 다루는 사람의 역량에서 함께 나므로, 도구는 같은 계층에서 기준으로 비교해 확인 날짜와 함께 기록하고, 역량은 실제 행동으로 평가해 가장 낮은 것부터 연습합니다.

생성형 AI 도구의 결과는 도구의 종류와 그 도구를 다루는 사람의 역량에 따라 함께 달라집니다. 작업 목적, 데이터 정책, 연동 범위에 따라 도구의 용도가 갈립니다. 도구의 기능과 요금은 자주 변경됩니다. 그래서 새 도구가 나올 때마다 도구만 교체하면 결과가 나아지지 않고, 한 도구를 깊이 다루는 역량도 쌓이기 어렵습니다. 이 장에서는 생성형 AI 도구를 선택하는 방법과 도구를 다루는 자신의 역량을 진단하는 방법을 다룹니다.

도구는 사용자가 접하는 제품부터 모델까지 다섯 계층으로 나뉩니다. 비교는 같은 계층의 제품끼리 합니다. 비교의 기준은 세 가지 선택 기준(작업 목적, 데이터 정책, 연동 범위)과 세 가지 추가 확인 항목(계정 유형, 파일 처리, 비용)입니다. 역량은 AI 사용에 직접 필요한 활용 역량 다섯 가지와 그 바탕이 되는 기반 역량 다섯 가지로 나눕니다. 각 역량은 아는 내용보다 실제로 하는 행동을 기준으로 네 단계로 평가합니다. 평가 결과로는 연습할 역량을 정합니다. 프롬프트(Prompt) 구성 요소, 원문 대조, 입력 데이터 분류는 이 장에서 도구 선택과 역량 평가의 기준이 됩니다.

먼저 도구를 비교하는 기준과 생태계의 계층을 살펴봅니다. 이어서 범용 대화형 제품, 특화 도구, 데이터를 내부에 두고 직접 실행할 수 있는 오픈 가중치 모델(Open-weight Model), 연동 규격을 차례로 다룹니다. 그다음 선택 절차, 변화 확인 기준, 제품 비교 점검표를 익히고, 활용 역량과 기반 역량, 자기 평가표, 연습 방법을 다룹니다. 끝으로 자기 평가 예제에서 평가 결과로 연습할 역량을 정하고, 결과의 확인 방법을 정리합니다.

  • 도구는 같은 계층의 제품끼리 비교하고, 세 가지 선택 기준과 추가 확인 항목으로 선택합니다.
  • 기능과 요금은 자주 변경되므로, 비교 결과는 확인 위치와 날짜를 함께 기록합니다.
  • 역량 10개를 실제 행동 기준으로 네 단계로 평가하고, 단계가 가장 낮은 역량의 연습 과제부터 수행합니다.

제품 단위로 비교하는 세 가지 선택 기준

도구는 제품 단위로 비교하고, 세 가지 기준으로 후보를 좁힌 뒤, 추가 확인 항목을 점검해 최종 선택합니다.

  • 제품 단위 비교: 같은 회사의 제품도 용도와 기능이 다릅니다. 그래서 비교는 제품 단위로 합니다. 예를 들어 OpenAI의 ChatGPT는 대화용 제품이고, Codex는 코딩용 제품입니다. Anthropic도 대화형 제품 Claude와 코딩 도구 Claude Code를 따로 제공합니다.
  • 세 가지 선택 기준: 작업 목적, 데이터 정책, 연동 범위로 후보를 좁힙니다.
  • 추가 확인: 기능 사용 범위와 데이터 처리 정책은 같은 제품이라도 요금제(무료, 유료, 기업용)와 계정 유형(개인, 조직)에 따라 다릅니다. 그래서 후보를 정한 뒤 계정 유형, 파일 처리, 비용을 확인합니다. 비용에는 요금제별 사용 한도와 사용량에 따라 부과되는 API(Application Programming Interface) 요금이 있습니다.

항목마다 확인할 내용은 제품의 공식 안내에 있습니다. 예를 들어 데이터 정책에서는 제공 회사의 입력 데이터 학습 사용 여부, 사용 해제 설정, 보관 기간의 세 가지를 확인합니다. 표 7-1은 선택 기준과 추가 확인 항목마다 공식 안내에서 확인할 내용입니다.

비교할 도구의 종류는 기준을 적용하기 전에 알아야 하므로, 다음 절부터 생태계의 계층과 계층별 도구를 차례로 설명합니다.

제품부터 모델까지의 생태계 계층

생성형 AI 도구는 사용자가 접하는 제품부터 모델까지 제품, 에이전트(Agent), 연동, API, 모델의 다섯 계층으로 구성됩니다. 사용자는 제품과 에이전트를 직접 사용합니다. 연동 규격과 API는 그 아래에서 제품과 에이전트를 모델과 외부 도구에 연결합니다.

에이전트는 목표를 받아 도구 호출, 결과 확인, 다음 행동 결정을 반복하는 AI 시스템입니다.

AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 규격을 연동 규격이라고 합니다. MCP(Model Context Protocol)가 연동 규격의 예입니다.

도구는 같은 계층끼리 비교합니다. 제품인 ChatGPT와 모델인 GPT를 비교하면 기준이 맞지 않기 때문입니다. Claude처럼 제품의 이름이 모델 계열의 이름과 같은 경우도 있습니다. 그래서 비교할 때는 이름이 어느 계층을 가리키는지 먼저 확인합니다. 표 7-2는 계층마다의 역할과 대표 사례입니다.

작업을 가리지 않는 범용 대화형 제품

글쓰기, 요약, 분석, 질의응답처럼 특정 분야에 한정되지 않는 작업을 대화로 처리하는 제품을 범용 대화형 제품이라고 합니다. 표 7-3은 이 장에서 예로 드는 제품 세 가지의 발표 주체, 모델 계열, 사용 형태입니다. 세 제품은 비교 기준을 적용할 예로 든 것이며, 우열을 가리는 목록이 아닙니다.

세 제품의 현재 기능은 각 회사의 공식 안내에서, 모델과 API는 개발 문서에서 확인합니다. 공식 안내는 ChatGPT, Claude, Gemini의 도움말 페이지이고, 개발 문서는 OpenAI, Anthropic, Google의 개발자 문서입니다.

기능 이름, 모델 버전, 요금제는 자주 변경됩니다. 그래서 비교는 기능 목록 대신 세 제품에 공통인 기능 유형을 기준으로 합니다. 기능 유형은 파일 첨부, 웹 검색, 프로젝트, 메모리(Memory), 심층 조사, 코드 실행의 여섯 가지입니다. 기능의 이름과 제공 범위는 제품과 요금제에 따라 다릅니다. 표 7-4는 유형마다 용도와 함께 확인할 항목을 보여 줍니다.

메모리는 이전 대화의 정보를 저장해 다음 대화에 반영하는 기능입니다. 사용자가 직접 적어 두는 사용자 지침과 프로젝트에 둔 지침도 다음 대화에 함께 반영됩니다. 저장된 정보는 같은 맥락을 매번 입력하는 수고를 줄입니다. 반면, 저장된 정보는 새 대화의 결과에도 영향을 줍니다. 그래서 사용자는 메모리에 저장된 정보를 주기적으로 확인하고, 민감한 정보는 삭제합니다. 업무 특성상 저장 자체가 맞지 않으면 메모리 해제를 검토합니다.

한 작업에 맞춘 특화 도구

특정 작업에 맞춰 설계된 도구를 특화 도구라고 합니다. 특화 도구의 유형은 검색 특화, 업무 도구 내장, 코딩, 이미지 생성, 영상 생성, 문서 기반 조사의 여섯 가지입니다. 범용 제품으로도 같은 작업을 수행할 수 있지만, 특화 도구는 그 작업에 필요한 기능(출처 링크, 저장소 연결, 시안 편집 등)을 기본으로 제공합니다.

특화 도구를 선택할 때는 제품 이름보다 해결하려는 작업과 필요한 기능의 일치 여부를 먼저 확인합니다. 표 7-5는 유형별 용도와 제품 사례입니다. 제품 사례는 유형을 이해하기 위한 참고이며, 제품의 순위나 대표성을 뜻하지 않습니다.

데이터를 내부에 두는 오픈 가중치 모델

모델이 학습으로 정하는 내부 수치를 가중치(Weight)라고 합니다. 학습을 마친 모델의 가중치 파일을 공개해 누구나 내려받아 자기 컴퓨터나 서버에서 실행할 수 있게 한 모델을 오픈 가중치 모델이라고 합니다. 오픈 가중치 모델에는 Alibaba의 Qwen 계열, Meta의 Llama 계열, Mistral AI의 모델, OpenAI의 gpt-oss 등이 있습니다.

범용 제품과 특화 도구처럼 제공 회사의 서버에서 모델을 실행하고, 사용자는 화면이나 API로 이용하는 방식을 이 장에서는 제품형 서비스라고 합니다. 제품형 서비스와 오픈 가중치 모델의 가장 큰 차이는 데이터의 외부 전송 여부입니다. 오픈 가중치 모델을 내부 장비에서 직접 운영하면 데이터를 내부에 둘 수 있지만, 실행 장비와 운영 인력이 필요합니다. 반면, 같은 오픈 가중치 모델을 외부 회사가 운영하는 서버에서 API로 사용하면 데이터는 그 회사의 서버로 전송됩니다.

학습을 마친 모델을 특정 데이터로 추가 학습시키는 일을 미세 조정(Fine-tuning)이라고 합니다. 오픈 가중치 모델은 가중치 파일이 공개되어 있으므로, 사용자가 내려받아 미세 조정을 직접 할 수 있습니다. 표 7-6은 두 방식을 데이터 위치, 도입 준비, 가중치 접근, 비용 조건, 이용 조건의 다섯 가지로 비교합니다.

상업적 이용 조건은 라이선스마다 다릅니다. 그래서 도입하기 전에 모델 배포 페이지에서 라이선스 원문을 확인합니다.

외부 도구와 연결하는 연동 규격 MCP

MCP는 AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 연동 규격입니다. 연동 규격이 없으면 제품마다 연결 기능을 따로 개발해야 합니다. Anthropic은 2024년 11월 MCP를 공개했습니다48.

문서 저장소, 일정, 업무 도구 같은 외부 시스템의 데이터와 기능을 MCP 방식으로 제공하는 프로그램을 MCP 서버라고 합니다. MCP를 지원하는 제품은 같은 MCP 서버에 연결해 그 서버의 데이터와 기능을 사용할 수 있습니다. 따라서 제품이 MCP를 지원한다는 사실은 선택 기준의 연동 범위를 판단하는 근거의 하나가 됩니다.

버전 주석 (2026년 10월) Anthropic은 2025년 12월 9일 MCP를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기부했습니다49. Anthropic은 같은 발표에서 ChatGPT, Gemini 등이 MCP를 채택했다고 밝혔습니다49.

MCP 서버에 연결된 AI는 그 서버가 허용하는 범위에서 데이터를 읽고 작업을 수행합니다. 그래서 사용자는 연결하기 전에 서버를 만든 주체와 서버가 읽고 수정할 수 있는 데이터의 범위를 확인합니다.

유형, 데이터, 기준 순서의 선택 절차

도구 선택은 제품 유형 결정, 데이터 반출 판단, 후보 비교의 세 단계로 진행합니다. 제품 유형은 첫 단계에서 작업 목적으로 정합니다.

입력할 데이터를 외부로 보낼 수 있는지를 데이터 반출 가능 여부라고 합니다. 판단 기준은 입력 데이터 분류와 조직의 사용 정책입니다. 입력 데이터 분류는 데이터를 공개 정보, 내부 정보, 개인정보, 고유식별정보, 영업 비밀의 다섯 유형으로 나누고 유형마다 입력할 수 있는 환경을 정한 기준입니다(Chapter 6).

데이터를 보낼 수 없으면 제품형 서비스 대신 오픈 가중치 모델의 직접 운영을 검토합니다. 반면, 데이터를 보낼 수 있으면 표 7-1의 선택 기준과 추가 확인 항목으로 같은 유형의 제품을 비교해 하나를 선택합니다.

그림 7-1은 위에서 아래로 읽습니다. 1 영역은 작업 목적 다섯 가지를 범용 대화형 제품과 특화 도구 유형에 잇습니다. 이미지 생성과 영상 생성은 한 줄로 묶었고, 문서 기반 조사는 그림에서 생략했습니다. 2 데이터 반출 가능 여부에서 반출이 불가하면 오른쪽의 오픈 가중치 모델 검토로, 가능하면 아래의 3 후보 비교로 이어집니다.

제품별 비교 결과는 뒤의 제품 비교 점검표에 기록합니다.

변화를 확인하는 네 가지 기준

도구의 기능과 정책은 빠르게 변경됩니다. 그래서 새 제품과 모델에 관한 정보는 원문으로 확인한 뒤 비교 결과에 반영합니다. 정보는 제품 변화, 연구 결과, 성능 수치, 도입률 통계의 네 가지로 나뉘고, 종류마다 확인할 곳과 기준이 다릅니다. 이 장의 제품 정보도 2026년 10월에 확인한 정보이므로 읽는 시점에는 달라져 있을 수 있습니다.

  • 제품 변화: 제품 공식 공지와 개발 문서의 변경 기록을 확인합니다.
  • 연구 결과: 논문 원문과 발표 기관을 확인합니다.
  • 성능 수치: 발표 주체가 측정한 값인지, 제삼자가 재현한 값인지 구분합니다.
  • 도입률 통계: 시범 사용과 실제 운영을 구분했는지 확인합니다.

확인 날짜를 남기는 제품 비교 점검표

선택 기준을 적용해 대화형 제품을 비교하는 기록 양식을 제품 비교 점검표라고 합니다. 기능과 요금은 자주 변경됩니다. 그래서 점검표에는 확인한 값과 함께 확인 위치와 확인 날짜를 기록합니다. 확인 위치는 값을 확인한 공식 안내나 개발 문서의 URL입니다. 기능이 변경되면 이 URL에서 값을 다시 확인합니다.

비교 대상은 표 7-3의 세 제품입니다. 표 7-7의 항목은 표 7-1의 선택 기준과 추가 확인 항목을 같은 순서로 옮긴 것입니다. 빈칸은 도구를 선택할 때 항목마다 제품별 공식 안내를 확인해 채웁니다.

AI 사용에 직접 필요한 활용 역량

결과 품질은 같은 도구를 선택해도 사용자의 역량에 따라 달라집니다. Dell'Acqua 외의 실험(머리말)에서 AI를 사용한 집단은 과제가 AI의 능력 범위 밖에 있을 때 AI를 사용하지 않은 집단보다 정답률이 낮았습니다. 이 차이는 AI에 맡길 과제를 구분하는 역량이 결과를 좌우할 수 있음을 보여 줍니다.

AI 사용에 직접 필요한 역량을 이 장에서는 활용 역량이라고 합니다. 활용 역량은 문제 정의, 지시 작성, 검증, 도메인 지식, 윤리 판단의 다섯 가지입니다. 지시 작성의 행동 기준은 프롬프트 구성 요소(목적, 역할, 맥락, 출력 형식, 제약 조건)를 갖춘 프롬프트입니다. 검증의 행동 기준은 원문 대조입니다.

입력 데이터 분류에서 고유식별정보처럼 입력하지 않는다고 정한 데이터를 입력 금지 데이터라고 합니다. AI로 만든 결과물임을 법령이나 조직 정책에 따라 밝혀야 하는 의무는 표시 의무라고 합니다. 윤리 판단의 행동 기준은 이 두 가지의 준수입니다. 표 7-8은 활용 역량마다의 정의와 행동 기준입니다.

결과를 판단하는 기준인 도메인 지식

도메인 지식은 AI 결과를 판단하는 기준이 됩니다. 분야의 정답과 오답을 구분할 수 있어야 그럴듯한 오류도 발견할 수 있습니다. 회계 기준을 아는 사람은 AI가 작성한 분개에서 오류를 찾고, 의료 기준을 아는 사람은 AI가 요약한 투약 기록에서 누락을 찾습니다. 반면, 분야의 기준을 모르는 사람은 문장이 자연스러울수록 오류를 발견하기 어렵습니다.

활용 역량의 바탕인 기반 역량

활용 역량의 바탕이 되는 일반 역량을 이 장에서는 기반 역량이라고 합니다. 기반 역량은 AI 사용에 한정되지 않지만, AI 결과를 판단하고 활용하는 단계에서 차이를 만듭니다. 비판적 사고, 창의성, 소통과 협업, 메타인지, 학습 민첩성의 다섯 가지가 기반 역량입니다. 메타인지는 이 가운데 AI 결과를 스스로 확인할 수 있는 분야를 가리는 기준이 됩니다. 표 7-9는 기반 역량마다의 정의와 AI 사용에서의 역할입니다.

행동으로 평가하는 자기 평가표

자기 평가는 역량 10개마다 현재 행동에 가장 가까운 단계를 정하는 방식입니다. 단계는 알고 있는 내용보다 실제로 하고 있는 행동을 기준으로 선택합니다. 단계가 올라갈수록 행동은 AI 결과의 수용에서 일부 판단, 정해진 기준에 따른 확인과 작업, 기준의 작성과 공유로 옮겨 갑니다. 표 7-10은 1, 2단계, 표 7-11은 3, 4단계의 행동 기준입니다.

평가가 끝나면 모든 역량을 한 번에 연습하지 않고, 단계가 가장 낮은 두세 역량의 과제부터 수행합니다. 평가의 목적은 점수보다 연습할 역량의 결정에 있습니다. 그래서 낮은 단계로 평가되어도 지금의 행동을 그대로 적습니다. 역량별 연습 과제는 다음 절에 정리했습니다.

하루 안에 끝내는 역량별 연습

역량별 연습 과제는 실제 업무나 학습에서 하루 안에 끝낼 수 있는 크기입니다. 과제를 마친 뒤에는 표 7-10과 표 7-11로 다시 평가하고 단계의 변화를 기록합니다. 표 7-12는 역량마다 연습 과제 하나를 정리한 것입니다.

예제: 자기 평가의 연습 역량 선택

이 절에서는 자기 평가표를 가상의 자기 평가 결과(이하 자기 평가)에 적용합니다. 역량 10개마다 최근 행동을 근거로 단계를 선택하고, 가장 낮은 두 역량의 연습 계획을 세웁니다. 표 7-13은 단계 선택의 결과입니다. 근거가 된 최근 행동은 단계마다 함께 적어, 아는 내용보다 실제 행동으로 선택했는지 확인할 수 있게 합니다.

검증과 메타인지가 가장 낮은 단계(1단계)입니다. 두 역량은 서로 이어져 있습니다. 모르는 분야의 답을 확인 없이 사용하는 습관(메타인지)이 수치를 대조하지 않는 행동(검증)으로 나타날 수 있기 때문입니다.

표 7-14는 두 역량의 연습 과제를 표 7-12에서 가져오고, 다시 평가할 때 도달할 단계를 표 7-10과 표 7-11에서 정한 것입니다. 다시 평가할 기준은 연습 과제에서 직접 연습하는 행동의 단계로 정합니다. 검증 과제에서는 3단계 행동인 원문 대조를 그대로 연습하므로, 3단계를 기준으로 삼습니다. 메타인지 과제에서는 모르는 분야를 드러내 사용 전에 표시하는 행동을 연습하므로, 2단계를 기준으로 삼습니다.

결과에서는 근거 행동과 다시 평가할 기준의 두 가지를 확인합니다. 첫째, 표 7-13의 모든 단계에 근거 행동이 있는지 봅니다. 근거 행동을 적지 못한 역량은 단계를 아는 내용으로 선택했을 가능성이 큽니다. 둘째, 표 7-14의 다시 평가할 기준이 표 7-10, 표 7-11의 칸과 글자까지 같은지 봅니다. 기준이 다르면 연습 뒤에 같은 기준으로 다시 평가할 수 없습니다. 다시 평가해도 단계가 오르지 않았으면 같은 과제를 다른 작업에 한 번 더 적용합니다.
