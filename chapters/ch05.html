Chapter 5 AI를 활용한 학습, 자료 조사, 요약

학습과 연구에서 생성형 AI는 설명, 질문, 연습 문제, 요약, 자료 탐색을 돕고, 사용자는 사실과 출처를 확인합니다. 역할을 이렇게 나누는 이유는 AI가 학습을 대신하면 배운 것이 남지 않고, 출처 확인을 AI에 맡기면 AI가 만든 오류를 같은 AI가 확인하게 되기 때문입니다.

  • AI에게 답 대신 힌트와 질문을 요청하면 스스로 푸는 과정이 남습니다.
  • AI가 제시한 참고문헌은 원문을 열어 존재와 내용을 확인합니다.
  • 과제와 논문에 AI를 사용하기 전에 기관의 규정을 확인합니다.

활용 영역

학습과 연구에서 AI를 활용하는 영역은 일곱 가지이며, 영역마다 사용자가 확인할 사항이 다릅니다. 개념 설명은 교재와 일치하는지, 자료 탐색은 제안된 문헌이 실제로 존재하는지를 확인하는 식입니다. 표 5-1은 영역별 예제와 확인할 점입니다.

개념 설명 요청

개념 설명을 요청할 때는 수준, 형식, 분량을 지정합니다. 지정하지 않으면 설명의 수준이 요청한 사람과 맞지 않고, 교재와 비교하기도 어렵습니다. 아래 예제는 수준(금융 지식 없이 이해할 수 있는 수준), 형식(표), 추가 항목(혼동하는 개념)을 지정합니다.

복리를 금융 지식 없이 이해할 수 있게 설명해 줘.
단리와 복리를 비교하는 표를 작성하고,
처음 배울 때 자주 혼동하는 점 두 가지를 표 아래에 적어 줘.

설명이 이해되지 않으면 비유를 요청하기보다 다른 예시나 그림을 사용한 설명을 요청합니다. 비유는 개념의 일부만 대응하므로 잘못된 이해로 이어질 수 있습니다.

튜터로 활용

AI를 튜터로 활용할 때는 답을 주지 말라는 제약 조건을 먼저 둡니다. AI에게 답을 바로 받으면 과제는 끝나도 배운 것이 남지 않기 때문입니다. 아래 예제는 힌트를 한 번에 하나만 주고, 사용자가 제시한 답의 정오와 이유만 알려 주도록 지시합니다.

나는 확률을 처음 공부해.
다음 문제를 풀고 싶어. 정답과 풀이를 바로 알려 주지 마.
풀이가 멈춘 지점을 묻고, 한 번에 힌트 하나만 줘.
내가 답을 말하면 맞는지와 오답인 이유만 알려 줘.

<문제>
주사위 두 개를 던질 때 눈의 합이 7이 될 확률은?
</문제>

소크라테스식 질문

소크라테스식 질문은 질문하는 쪽과 답하는 쪽을 반대로 해 AI가 질문하고 사용자가 답하는 방법입니다. 개념을 설명할 수 있는지 스스로 확인하는 데 적합합니다. 질문을 쉬운 것부터 하나씩 받으면 이해가 끊기는 지점을 찾을 수 있습니다.

빈칸 템플릿은 부록 1에 있습니다.

[개념]을 내가 제대로 이해했는지 확인하고 싶어.
질문을 한 번에 하나씩 해 줘. 쉬운 질문에서 시작해 점점 어렵게 해 줘.
내 답에 오류가 있으면 정답을 말하지 말고, 잘못 이해한 부분을 다시 생각하게 하는 질문을 해 줘.
질문 다섯 개가 끝나면 내가 약한 부분을 정리해 줘.

노트와 복습 자료

AI는 강의 내용을 정해진 형식의 복습 자료로 변환하는 작업에 적합합니다. 형식마다 용도가 다르므로 복습 목적에 맞는 형식을 선택합니다. 표 5-2는 형식별 요청 방법과 용도입니다.

AI가 만든 복습 자료도 강의 원문과 대조합니다. 강의에서 강조한 내용이 누락되거나, 강의에 없는 내용이 섞일 수 있기 때문입니다.

학습 계획

학습 계획은 기간, 목표, 하루 가용 시간, 현재 수준을 입력해 주 단위 일정으로 요청합니다. 아래 템플릿의 대괄호 안에 자신의 조건을 입력하고, 점검 방법 열을 포함해 진도를 확인할 수 있게 합니다.

빈칸 템플릿은 부록 1에 있습니다.

나는 [기간] 안에 [목표]를 달성하려고 해.
하루에 사용할 수 있는 시간은 [시간]이고, 현재 수준은 [수준]이야.
주 단위 학습 계획을 표로 만들어 줘. 열: 주차, 학습 내용, 연습 과제, 점검 방법.
마지막 주에는 전체 복습과 모의 평가를 포함해 줘.

외국어 학습

외국어 학습에서 AI는 교정, 대화 상대, 어휘 정리의 세 가지 역할을 맡습니다.

  • 작문 교정: 자신이 작성한 문장을 교정하게 하고, 수정 이유를 문법 항목별로 설명하게 합니다.
  • 상황 대화: 식당 주문, 면접처럼 상황을 정해 AI와 역할 대화를 합니다.
  • 어휘 정리: 읽은 글에서 모르는 단어를 선택해 예문과 함께 정리하게 합니다.

발음과 억양은 문자 대화로 확인할 수 없으므로 음성 기능이나 원어민 자료로 확인합니다.

연구 단계별 활용

연구에서는 단계마다 AI가 맡을 작업과 사람이 맡을 일을 나눕니다. 기준은 결과에 대한 책임입니다. 연구 질문 확정, 방법 결정, 해석, 결론 작성처럼 연구자가 책임지는 판단은 사람이 맡고, 후보 제안과 정리는 AI가 맡습니다(표 5-3).

참고문헌 확인

AI가 제시한 참고문헌은 존재, 서지 정보, 인용 문장을 차례로 확인한 뒤에만 사용합니다. 대화형 AI는 존재하지 않는 논문 제목, 저자, 쪽수를 생성하기도 합니다. 모델이 사실이 아니라 확률로 문장을 만들기 때문에, 그럴듯한 서지 정보도 실제 문헌과 일치한다는 보장이 없습니다. 확인 순서는 네 단계입니다.

  1. 학술 검색 서비스에서 제목으로 검색해 존재를 확인합니다.
  2. DOI나 출판사 페이지에서 저자, 연도, 학술지를 대조합니다.
  3. 인용할 문장이 원문에 있는지 본문에서 확인합니다.
  4. 확인하지 못한 문헌은 사용하지 않습니다.

문헌 탐색은 AI에게 논문 제목을 받는 것보다, 검색어를 받아 학술 검색 서비스에서 직접 검색하는 방식이 안전합니다. 검색 결과는 실제 문헌만 보여 주기 때문입니다.

학술 윤리

과제나 논문에 AI를 사용하기 전에는 해당 기관의 규정을 확인하고 사용 범위를 밝힙니다. 규정은 기관마다 다르기 때문입니다. Nature는 2023년 1월 사설에서 대규모 언어 모델(Large Language Model, LLM)을 논문 저자로 인정하지 않으며, 모델을 사용한 경우 방법 또는 감사의 글에 밝히도록 하는 원칙을 발표했습니다. 사용 사실을 표기하는 방법은 Chapter 8에서 다룹니다.

AI 탐지 도구의 판정은 부정행위의 근거로 사용하지 않습니다. OpenAI는 2023년 1월 공개한 AI 텍스트 판별기를 정확도가 낮다는 이유로 2023년 7월 20일 제공 중단했고, Liang 외(2023)는 여러 판별기가 영어 비원어민의 글을 AI가 작성한 글로 잘못 판정하는 경향을 보고했습니다. 사람이 작성한 글을 AI가 작성한 글로 판정하거나, AI가 작성한 글을 사람이 수정하면 탐지하지 못할 수 있으므로, 탐지 결과만으로 판단하지 않고 작성 과정과 초안 기록을 함께 확인합니다.

생성형 AI, 묻고 확인하고 활용하기: 작동 원리, 프롬프트, 검증, 책임.
