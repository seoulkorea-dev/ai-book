# Chapter 5 명세: AI를 활용한 학습, 자료 조사, 요약

- 주장 한 줄: AI가 설명하고 정리한 내용은 스스로 이해하고 원문으로 확인해야 지식과 근거가 되므로, 학습에는 답 대신 힌트를 받고, 요약과 문헌과 계산은 원문과 공식으로 확인합니다(BOOK_SPEC 4절).
