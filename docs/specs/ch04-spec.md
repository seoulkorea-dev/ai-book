# Chapter 4 명세: 환각 대응과 교차 검증

- 주장 한 줄: AI의 답은 정확하든 아니든 같은 문체로 나오므로, 오류가 있을 때 영향이 큰 사실부터 원문과 독립된 출처로 교차 검증하고, 프롬프트는 평가 기준을 먼저 정해 한 요소씩 개선합니다(BOOK_SPEC 4절).
- 할 수 있게 되는 일: 환각을 의심할 지점을 찾고, 결과를 원문과 독립된 출처에 대조해 확인한 뒤 기준에 따라 프롬프트를 개선
- 앞 장과의 관계: Chapter 1의 다음 토큰 선택과 지식 기준일(환각의 원인), Chapter 2의 구성 요소(실패 유형별 수정 요소), Chapter 3의 자기 검토 요청(같은 모델에게 다시 묻는 것은 검증이 아님)

## 그림(Q-068: 목적부터 다시 설계)
- 그림 4-1(흐름형, 영역 셋): 독자가 알게 될 것은 "검색과 답변 작성은 다른 주체가 맡고, 사람은 모델에게 다시 묻지 않고 출처 문서를 직접 연다". 사람(질문, 원문 대조), 검색 시스템(1 문서 검색, 문서 저장소), 모델(2 답변 생성, 3 출처 표시). 점선 화살표는 사람이 출처 문서를 여는 경로. 결론 제목 "검색 증강 생성은 찾은 문서 안에서 답하고, 사람은 그 문서와 대조합니다". 버린 시안: 원본처럼 한 줄 흐름(주체 구분과 사람의 대조 경로가 없음)
- 그림 4-2(흐름형, 영역 둘): 독자가 알게 될 것은 "기준은 결과를 보기 전에 정하고, 반복은 3~5단계뿐". 실행 전에 한 번(1, 2), 합격할 때까지 반복(3 → 4 → 불합격 5 → 점선 3), 합격 뒤 6. 결론 제목 "기준은 실행 전에 정하고, 합격할 때까지 한 요소씩 수정합니다". 버린 시안: 원본처럼 여섯 칸 순환(어느 단계가 반복되는지 영역으로 보이지 않음)
