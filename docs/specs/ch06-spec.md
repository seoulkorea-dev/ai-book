# Chapter 6 명세: AI를 활용한 업무, 기획서 초안, 창작

- 주장 한 줄: AI는 요청받은 내용을 만들 뿐 결과가 어디에 쓰이고 누구에게 영향을 주는지 판단하지 않으므로, 업무와 창작에서는 AI에게 초안과 계산을 맡기고 범위, 데이터, 결정, 권리 확인은 사람이 맡습니다(BOOK_SPEC 4절).
