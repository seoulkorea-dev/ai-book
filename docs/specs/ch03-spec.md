# Chapter 3 명세: 고급 프롬프트 기법과 AI 자기 검토

- 주장 한 줄: 프롬프트 구성 요소만으로는 처리 방식이 정해지지 않으므로, 작업의 성격에 맞는 기법으로 처리 방식을 지정하고 자기 검토 요청으로 사람이 확인할 지점을 드러냅니다(BOOK_SPEC 4절).
- 할 수 있게 되는 일: 작업에 맞는 기법(Few-shot, 단계별 추론, ReAct, 프롬프트 체이닝)을 고르고 조합하며, 자기 검토와 개선 요청으로 결과를 다시 점검
- 앞 장과의 관계: Chapter 1의 다음 토큰 선택(단계별 추론과 생성 설정의 근거), Chapter 2의 프롬프트 구성 요소(무엇을 원하는지)에 처리 방식(어떻게)을 더함. Chapter 1 생성 설정 링크(ch03#sampling)는 id 유지
