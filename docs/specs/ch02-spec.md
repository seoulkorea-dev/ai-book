# Chapter 2 명세: 프롬프트 작성의 기본

- 주장 한 줄: 모델은 프롬프트에 적힌 정보만으로 작업하므로, 필요한 프롬프트 구성 요소를 갖추고 입력 자료를 지시와 나눠 요청하면 모델이 짐작으로 채우는 부분이 줄어듭니다(BOOK_SPEC 4절, Q-010).
- 할 수 있게 되는 일: 프롬프트 구성 요소를 갖춘 프롬프트를 작성하고 입력 자료를 구분해 배치
- 앞 장과의 관계: Chapter 1의 프롬프트 핵심 정의(모델에 주는 입력 전체)와 작동 방식(확률이 높은 말 선택, 긴 입력 중간 정보 덜 활용)이 명확성 원칙과 입력 자료 위치의 근거

## 그림
- 그림 2-1(비교형): 짧은 자료와 긴 자료의 배치 순서. 영역 머리 띠(10.4), 점선 칸은 입력 자료, 실선 칸은 지시. 결론 제목 "긴 자료는 앞에 두고 지시를 끝에 한 번 더 적습니다". 시안 하나: 원본 그림의 두 열 구조를 새 규격으로 옮긴 것이라 구조 선택지 없음
