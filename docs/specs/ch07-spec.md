## 그림(Q-068: 목적부터 다시 설계)
- 그림 7-1(흐름형): 독자가 알게 될 것은 "유형을 먼저 정하고, 데이터 조건이 제품형 서비스와 오픈 가중치 모델을 가르고, 마지막에 기준으로 비교한다". 1 영역(목적 다섯 가지 → 제품 유형), 2 데이터 반출 가능 여부(없음 → 오픈 가중치 모델), 3 후보 비교. 결론 제목 "작업 목적으로 유형을 정하고, 데이터 조건과 기준으로 좁힙니다". 버린 시안: 원본처럼 목적 → 유형 다섯 줄 뒤 선택 기준 상자와 맨 아래 데이터 분기(데이터 조건이 비교 뒤에 와서 판단 순서가 거꾸로임)
