# Chapter 1 명세: 생성형 AI의 기본 원리와 한계

- 주장 한 줄: 생성형 AI는 다음 토큰을 예측해 문장을 이어 가므로, 결과를 어디까지 신뢰할지는 이 작동 방식에서 비롯된 강점과 약점을 기준으로 판단합니다(BOOK_SPEC 4절 초안, Q-010).
- 할 수 있게 되는 일: 생성형 AI가 결과를 만드는 방식과 그 방식에서 비롯되는 강점과 약점을 설명하고, 결과에서 확인할 곳을 정함

## 그림
- 그림 1-1(구성형): 인공지능 ⊃ 머신 러닝 ⊃ 딥 러닝 ⊃ 생성형 AI ⊃ 대규모 언어 모델, 이미지, 음성, 영상 생성 모델. 결론 제목 "생성형 AI는 딥 러닝으로 새 결과물을 만드는 기술입니다"
- 그림 1-2(흐름형, 새로 그림): 네 단계와 반복, 종료. 결론 제목 "대규모 언어 모델은 다음 토큰 예측을 반복해 문장을 만듭니다"
- 시안 두 개를 만들지 않은 이유: 그림 1-1은 원본과 같은 포함 관계 구조를 새 규격으로 다시 그린 것이고, 그림 1-2는 원본 본문의 번호 목록(네 단계)을 그대로 흐름으로 옮긴 것이라 구조 선택지가 없음
