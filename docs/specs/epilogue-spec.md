# 마치며 명세

- 역할(플레이북 16.2): 장별 원칙을 모아 책의 결론으로 닫음. 장별 원칙 목록은 각 장 원칙 문장과 같은 뜻(여기서는 같은 문장). 시작하며와 같은 그림이나 설명을 되풀이하지 않음. 다음 할 일은 실제 장의 내용과 맞음.
- 한 문장 원칙과 절 구성(원리에서 책임까지, 이번 주에 시작할 다섯 가지, 앞으로의 변화, 마지막 제언) 유지(Q-014).

## 바꾼 것
- "원리에서 책임까지": 장별 설명 다섯 문단을 흐름 한 문단과 여덟 장의 원칙 문장 목록(각 장 #principle 링크)으로(Q-014)
- "이 책" 일곱 곳 삭제(Q-018), 기준 일자 날짜 삭제("기준 일자 이후", Q-002), "참고문헌" 표현 삭제(Q-029)
- 다섯 가지 할 일의 표현을 7장(단계가 가장 낮은 역량), 4장(차수별 수정 기록)과 맞춤
- 앞으로의 변화: 에이전트 정의를 되살리고, 표 8-9 링크 문구를 도착과 맞춤, EU 인공지능법 위첨자
- 6~8장 원칙 문장은 해당 장 병합 뒤 다시 대조
