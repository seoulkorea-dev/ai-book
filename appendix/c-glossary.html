C. 용어 사전

이 책에 나오는 용어를 한국어 가나다순, 영어 알파벳순으로 정리합니다.

용어

검색 증강 생성 (RAG, Retrieval-Augmented Generation)
질문과 관련된 문서를 검색해 프롬프트에 넣고 답을 생성하는 방식입니다.
대규모 언어 모델 (LLM, Large Language Model)
대량의 텍스트로 학습해 다음 토큰을 예측하는 생성형 모델입니다.
딥페이크 (deepfake)
실존 인물이나 사물을 실제처럼 보이게 합성한 이미지, 음성, 영상입니다.
멀티모달 (multimodal)
텍스트, 이미지, 음성 등 여러 형태의 데이터를 함께 처리하는 성질입니다.
미세 조정 (fine-tuning)
학습을 마친 모델을 특정 데이터로 추가 학습시키는 작업입니다.
사전 학습 (pre-training)
대량의 일반 데이터로 모델의 기본 능력을 만드는 첫 학습 단계입니다.
사람의 검토 (human in the loop)
AI 결과가 효력을 갖기 전에 사람이 확인하고 승인하는 절차입니다.
시스템 프롬프트 (system prompt)
대화 전체에 적용되는 기본 지시로, 사용자 메시지보다 앞에 놓입니다.
에이전트 (agent)
목표를 받아 도구 호출, 결과 확인, 다음 행동 결정을 반복하는 AI 시스템입니다.
역할 부여 (role prompting)
모델에게 특정 직무나 관점을 지정하는 프롬프트 작성 방법입니다.
임베딩 (embedding)
텍스트의 의미를 숫자 벡터로 바꾼 표현으로, 의미가 가까운 문서 검색에 씁니다.
추론 모델 (reasoning model)
답하기 전에 내부 추론 과정을 거치는 모델입니다.
컨텍스트 윈도우 (context window)
모델이 한 번에 처리하는 토큰의 최대 개수입니다.
토큰 (token)
모델이 처리하는 텍스트 단위로, 단어 전체이거나 단어의 일부입니다.
트랜스포머 (Transformer)
어텐션 연산으로 입력의 각 위치 사이 관계를 계산하는 신경망 구조입니다.
편향 (bias)
학습 데이터의 불균형이 결과에 반영되어 특정 집단에 불공정한 결과를 내는 현상입니다.
프롬프트 (prompt)
모델에 주는 입력 전체로, 지시, 맥락, 입력 데이터, 출력 형식으로 구성합니다.
프롬프트 인젝션 (prompt injection)
입력 데이터에 숨긴 문장으로 AI가 원래 지시와 다른 행동을 하게 만드는 공격입니다.
프롬프트 체이닝 (prompt chaining)
작업을 여러 프롬프트로 나누고 앞 결과를 다음 입력으로 쓰는 방법입니다.
환각 (hallucination)
사실이 아니거나 입력과 맞지 않는 내용을 사실처럼 생성하는 현상입니다.
Chain of Thought (CoT, 단계별 추론)
답을 내기 전에 추론 과정을 단계별로 쓰게 하는 프롬프팅 기법입니다.
Few-shot
입력과 출력 예시 몇 개를 프롬프트에 넣어 작업 방식을 보여 주는 기법입니다.
MCP (Model Context Protocol)
AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 규격입니다.
RLHF (Reinforcement Learning from Human Feedback)
사람의 비교 평가를 보상으로 삼아 모델을 추가 학습시키는 방법입니다.
Zero-shot
예시 없이 지시만으로 작업을 요청하는 방법입니다.
