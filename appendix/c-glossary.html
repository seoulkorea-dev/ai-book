부록

C. 용어 사전

이 부록은 이 책에 나오는 용어를 정의합니다. 한국어 용어는 가나다순, 영어 약어와 용어는 알파벳순으로 정리했으며, 정의는 본문에서 사용한 뜻과 일치합니다.

한국어 용어

가명처리
추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보의 일부를 삭제하거나 대체하는 처리입니다. 「개인정보 보호법」의 용어입니다.
가중치 (weight)
모델이 학습으로 정하는 내부 수치입니다. 오픈 가중치 모델은 이 수치를 담은 파일을 공개합니다.
검색 증강 생성 (RAG, Retrieval-Augmented Generation)
질문과 관련된 문서를 검색해 프롬프트에 포함하고 답을 생성하는 방식입니다.
과적합 (overfitting)
모델이 학습 데이터에 지나치게 맞춰져 새로운 데이터에서 성능이 떨어지는 현상입니다.
그라운딩 (grounding)
모델의 답을 제공한 문서나 검색 결과 같은 근거에 묶어 두는 방법입니다.
답변 보류 (abstention)
근거가 부족할 때 추측하지 않고 모른다고 답하는 것입니다.
대규모 언어 모델 (LLM, Large Language Model)
대량의 텍스트로 학습해 다음 토큰을 예측하는 생성형 모델입니다.
딥 러닝 (deep learning)
여러 층의 신경망으로 데이터를 학습하는 머신 러닝 방법입니다.
딥페이크 (deepfake)
실존 인물이나 사물을 실제처럼 보이게 합성한 이미지, 음성, 영상입니다.
머신 러닝 (machine learning)
명시적인 규칙 대신 데이터에서 규칙을 학습하는 방법입니다.
멀티모달 (multimodal)
텍스트, 이미지, 음성 등 여러 형태의 데이터를 함께 처리하는 성질입니다.
메모리 (memory)
대화형 제품이 이전 대화의 정보를 저장해 다음 대화에 반영하는 기능입니다.
모달리티 (modality)
텍스트, 이미지, 음성처럼 데이터가 표현되는 형태입니다.
미세 조정 (fine-tuning)
학습을 마친 모델을 특정 데이터로 추가 학습시키는 작업입니다.
바이브 코딩 (vibe coding)
코드를 거의 읽지 않고 자연어로 지시하며 실행 결과만 보고 수정해 나가는 방식입니다. Andrej Karpathy가 2025년 2월 처음 사용했습니다.
벡터 데이터베이스 (vector database)
임베딩을 저장하고 의미가 가까운 항목을 찾는 데이터베이스입니다.
사람의 검토 (human in the loop)
AI 결과가 효력을 갖기 전에 사람이 확인하고 승인하는 절차입니다.
사전 학습 (pre-training)
대량의 일반 데이터로 모델의 기본 능력을 만드는 첫 학습 단계입니다.
생성형 AI (generative AI)
학습한 패턴을 바탕으로 새로운 텍스트, 이미지, 음성, 코드를 만드는 AI입니다.
섀도 AI (shadow AI)
조직이 파악하지 못한 채 사용되는 AI 도구와 에이전트입니다. 정책 없이 직원이 개인 계정으로 사용하는 경우가 대표적입니다.
선호 학습 (preference learning)
사람이나 AI가 비교 평가한 답변으로 모델이 선호되는 답변을 내도록 추가 학습하는 단계입니다. RLHF가 대표 방법입니다.
시스템 프롬프트 (system prompt)
대화 전체에 적용되는 기본 지시로, 사용자 메시지보다 앞에 놓입니다.
어텐션 (attention)
입력의 각 위치가 다른 위치와 얼마나 관련되는지 계산하는 연산입니다.
에이전트 (agent)
목표를 받아 도구 호출, 결과 확인, 다음 행동 결정을 반복하는 AI 시스템입니다.
역할 부여 (role prompting)
모델에게 특정 직무나 관점을 지정하는 프롬프트 작성 방법입니다.
오픈 가중치 모델 (open-weight model)
학습을 마친 모델의 가중치 파일을 공개해 누구나 내려받아 실행할 수 있는 모델입니다.
임베딩 (embedding)
텍스트의 의미를 숫자 벡터로 변환한 표현으로, 의미가 가까운 문서를 검색할 때 사용합니다.
자동화 편향 (automation bias)
자동화 시스템의 결과를 자기 판단이나 다른 정보보다 더 신뢰하는 경향입니다.
적응형 추론 (adaptive thinking)
모델이 작업 난이도에 따라 추론량을 스스로 정하는 방식입니다. 추론량의 상한은 노력 수준(effort) 설정으로 조절합니다.
정렬 (alignment)
모델이 사람의 의도와 가치에 맞게 행동하도록 만드는 연구와 기법입니다.
지시 학습 (instruction tuning)
지시와 모범 답변의 쌍으로 모델이 지시를 따르도록 추가 학습하는 단계입니다.
지식 기준일 (knowledge cutoff)
모델 학습 데이터에 포함된 정보의 마지막 시점입니다.
추론 (inference)
학습을 마친 모델이 입력을 받아 출력을 만드는 과정입니다. 추론 모델의 추론(reasoning)과 구분합니다.
추론 모델 (reasoning model)
답하기 전에 내부 추론 과정을 거치는 모델입니다.
컨텍스트 윈도 (context window)
모델이 한 번에 처리하는 토큰의 최대 개수입니다.
토크나이저 (tokenizer)
텍스트를 토큰으로 나누는 도구입니다. 모델마다 다릅니다.
토큰 (token)
모델이 처리하는 텍스트 단위로, 단어 전체이거나 단어의 일부입니다.
트랜스포머 (Transformer)
어텐션 연산으로 입력의 각 위치 사이 관계를 계산하는 신경망 구조입니다.
파라미터 (parameter)
가중치와 같은 뜻으로, 모델 크기를 나타낼 때 사용합니다.
판별형 모델 (discriminative model)
입력을 정해진 분류 가운데 하나로 판단하는 모델입니다. 새로운 결과물을 만드는 생성형 모델과 구분합니다.
편향 (bias)
학습 데이터의 불균형이 결과에 반영되어 특정 집단에 불공정한 결과를 내는 현상입니다.
프롬프트 (prompt)
모델에 주는 입력 전체로, 목적, 역할, 맥락, 출력 형식, 제약 조건으로 구성됩니다.
프롬프트 엔지니어링 (prompt engineering)
원하는 결과를 얻도록 프롬프트를 설계하고 시험하고 수정하는 작업입니다.
프롬프트 인젝션 (prompt injection)
입력 데이터에 숨긴 문장으로 AI가 원래 지시와 다른 행동을 하게 만드는 공격입니다.
프롬프트 체이닝 (prompt chaining)
작업을 여러 프롬프트로 나누고 앞 결과를 다음 입력으로 사용하는 방법입니다.
환각 (hallucination)
사실이 아니거나 입력과 맞지 않는 내용을 사실처럼 생성하는 현상입니다.

영어 약어와 용어

AGI (Artificial General Intelligence)
사람 수준으로 여러 분야의 지적 작업을 수행하는 AI를 가리키는 말입니다. 합의된 정의는 없습니다.
API (Application Programming Interface)
프로그램이 다른 프로그램의 기능을 호출하는 통로입니다. 모델 API는 사용한 토큰 수로 요금을 매깁니다.
Chain of Thought (CoT, 단계별 추론)
답을 내기 전에 추론 과정을 단계별로 작성하게 하는 프롬프트 기법입니다.
Constitutional AI
원칙 목록을 기준으로 AI가 스스로 답변을 평가하고 수정하게 하는 학습 방법입니다. Anthropic이 발표했습니다.
Diffusion model (확산 모델)
잡음에서 시작해 잡음을 단계적으로 제거하며 이미지를 만드는 생성 모델입니다.
Few-shot
입력과 출력 예시 몇 개를 프롬프트에 포함해 작업 방식을 보여 주는 기법입니다.
Foundation model (파운데이션 모델)
대량의 데이터로 사전 학습해 여러 작업에 맞춰 사용할 수 있는 모델입니다.
GPT (Generative Pre-trained Transformer)
OpenAI의 언어 모델 계열 이름입니다. 사전 학습한 트랜스포머 생성 모델이라는 뜻입니다.
In-context learning (맥락 내 학습)
모델의 가중치를 변경하지 않고 프롬프트 안의 예시만으로 작업 방식을 따르게 하는 성질입니다.
MCP (Model Context Protocol)
AI 애플리케이션이 외부 데이터와 도구에 연결하는 방식을 정한 공개 규격입니다.
ReAct (Reasoning and Acting)
추론과 도구 사용을 번갈아 수행하며 답을 찾는 방식입니다. AI 에이전트의 기본 동작 방식입니다.
RLHF (Reinforcement Learning from Human Feedback)
사람의 비교 평가를 보상으로 삼아 모델을 추가 학습시키는 방법입니다.
Temperature
다음 토큰을 선택할 때 확률 분포를 평평하게 또는 뾰족하게 만드는 설정입니다.
Top-p
누적 확률이 p가 될 때까지의 후보 안에서만 다음 토큰을 선택하게 하는 설정입니다.
Zero-shot
예시 없이 지시만으로 작업을 요청하는 방법입니다.
