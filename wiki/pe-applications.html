응용

작업 유형별 프롬프트 작성 요점입니다.

컨텍스트 캐싱

컨텍스트 캐싱은 여러 요청에 반복되는 긴 프롬프트 앞부분을 저장해 두고 재사용하는 API 기능입니다. 반복 부분을 프롬프트 앞에 두면 처리 시간과 비용이 줄어듭니다. 제공 여부와 요금은 API 문서에서 확인합니다.

미세 조정

미세 조정은 모델을 특정 데이터로 추가 학습시키는 작업입니다. 프롬프트와 RAG로 해결되지 않는 형식, 어조 요구가 있을 때 검토합니다.
