프롬프트 엔지니어링

연구

프롬프트 작성과 관련된 연구 주제입니다.

LLM 토큰화

토큰화는 텍스트를 토큰으로 나누는 과정입니다. 논문 Sennrich 외(2016)가 기계 번역에 적용한 BPE(Byte Pair Encoding) 방식은 자주 나오는 글자 조합을 하나의 토큰으로 합칩니다. 같은 뜻의 문장도 언어에 따라 토큰 수가 다릅니다.

Infini-attention

논문 Google 연구진(Munkhdalai 외, 2024)이 발표한 방식으로, 압축 메모리를 이용해 제한된 메모리로 긴 입력을 처리합니다.

LLM 정보 회수

긴 입력 속 특정 정보를 찾아내는 능력입니다. 논문 Liu 외(2023)는 정보가 입력 가운데에 있을 때 회수 성능이 떨어진다는 결과를 발표했습니다.

합성 데이터

모델이 생성한 데이터로 다른 모델을 학습시키거나 평가하는 방법입니다. 사람이 만든 데이터가 부족한 분야에 쓰며, 생성 데이터의 오류가 학습에 들어가지 않도록 검증합니다.

추론 전용 반도체

기업 Groq는 LLM 추론 전용 반도체 LPU(Language Processing Unit)를 발표했습니다. 추론 전용 반도체는 학습보다 응답 생성 속도에 초점을 둡니다.
