프롬프트 엔지니어링

기법

주요 프롬프팅 기법의 정의와 원 논문입니다.

Zero-shot

예시 없이 지시만으로 작업을 요청합니다. 단순한 요약, 번역, 분류에 씁니다.

Few-shot

입력과 출력 예시 몇 개를 넣습니다. 예시는 분류별로 고르게 구성합니다. 원 논문: 3 Brown 외(2020)

Chain of Thought

추론 과정을 단계별로 쓰게 합니다. 원 논문: 3 Wei 외(2022). 예시 없이 "단계별로 생각하라"는 지시만 붙이는 방식은 3 Kojima 외(2022)가 발표했습니다.

Self-consistency

같은 질문으로 추론을 여러 번 생성하고 가장 많이 나온 답을 채택합니다. 원 논문: 3 Wang 외(2022)

ReAct

추론과 도구 사용을 번갈아 수행합니다. 원 논문: 3 Yao 외(2022)

프롬프트 체이닝

작업을 여러 프롬프트로 나누고 앞 결과를 다음 입력으로 씁니다. 단계별로 결과를 확인합니다.
