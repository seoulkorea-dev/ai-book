프롬프트 엔지니어링

에이전트

AI 에이전트의 구성과 관련 규격, 프레임워크입니다.

AI 에이전트

에이전트는 목표를 받아 도구 호출, 결과 확인, 다음 행동 결정을 반복하는 AI 시스템입니다.

워크플로와 에이전트

기업 Anthropic은 「Building effective agents」(2024년 12월)에서 두 방식을 구분했습니다.

같은 글에서 Anthropic은 가장 단순한 방식부터 시작하고, 필요할 때만 복잡도를 높이도록 권장했습니다.

에이전트 구성 요소

함수 호출

함수 호출은 모델이 미리 정의된 함수의 이름과 인자를 구조화된 형식으로 출력하고, 애플리케이션이 그 함수를 실행해 결과를 돌려주는 방식입니다. 모델은 함수를 직접 실행하지 않습니다.

MCP (Model Context Protocol)

기업 Anthropic이 2024년 11월 공개한 연동 규격입니다. MCP 서버는 도구와 데이터를 제공하고, MCP 클라이언트(AI 애플리케이션)는 이를 호출합니다. 규격이 같으면 한 번 만든 서버를 여러 AI 애플리케이션에서 쓸 수 있습니다. 버전 주석 (2026년 9월): 기업 Anthropic은 2025년 12월 9일 MCP를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기부했고, ChatGPT, Gemini 등 다른 회사 제품도 MCP 연결을 지원합니다.

LangChain과 LangGraph

기업 LangChain은 LLM 애플리케이션을 만드는 오픈 소스 프레임워크입니다. 같은 개발사의 LangGraph는 에이전트의 상태와 실행 흐름을 그래프로 정의합니다.

컨텍스트 엔지니어링

컨텍스트 엔지니어링은 모델이 각 단계에서 보는 정보(지시, 도구 설명, 검색 결과, 대화 기록)를 선택하고 배치하는 작업입니다. 컨텍스트 윈도 한도 안에서 필요한 정보만 넣습니다.
