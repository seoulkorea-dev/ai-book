# 생성형 AI, 묻고 확인하고 활용하기: 작동 원리, 프롬프트, 검증, 책임

생성형 AI를 업무와 학습에 사용하는 사람을 위한 안내서입니다. 생성형 AI가 결과를 만드는 원리에서 시작해 프롬프트 작성, 결과 검증, 학습과 업무 활용, 도구 선택, 윤리와 조직 정책까지 다룹니다. 책 전체를 꿰는 원칙은 하나입니다. **AI는 초안을 만들고, 사람은 묻고 확인해 결정합니다.**

- 온라인으로 읽기: https://seoulkorea-dev.github.io/genai-book/
- 기준 일자: 2026년 10월 31일

## 배경

이 저장소는 먼저 완성한 원고(seoulkorea-dev/ai-book)를 다시 정리한 판입니다. 정리 전 원고는 `original` 브랜치에 그대로 두었습니다.

## 구성

시작하며, Chapter 1~8(기본 원리와 한계, 프롬프트 작성의 기본, 고급 프롬프트 기법과 AI 자기 검토, 환각 대응과 교차 검증, 학습과 자료 조사, 업무와 창작, 도구 선택과 역량 진단, 윤리와 법과 보안), 마치며, 부록(분야별 프롬프트 예문 모음, 용어 풀이, 참고 자료)
