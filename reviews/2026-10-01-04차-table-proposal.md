## 1. Chapter 1

### 표 1-5 생성형 AI의 강점과 약점 (전면 교체, 열 3개 유지)

| 구분 | 작업 유형 | 이유 |
|---|---|---|
| 강점 | 문서 초안 작성 | 같은 형식의 문서가 학습 데이터에 많아 형식과 문체를 안정적으로 재현 |
| 강점 | 요약, 정리 | 입력한 원문 안에서 내용을 재구성하므로 근거가 입력 범위 안에 있음 |
| 강점 | 번역, 문체 변환 | 언어와 문체 사이의 대응 관계를 대량의 텍스트로 학습 |
| 강점 | 아이디어 발상, 구조 제안 | 확률에 따라 토큰을 선택하므로 실행할 때마다 다른 후보를 생성 |
| 강점 | 코드 작성과 설명 | 공개 코드로 학습했고, 결과를 실행해 바로 검증 가능 |
| 강점 | 분류, 정보 추출 | 기준과 예시를 제공하면 정해진 형식으로 일정하게 출력 |
| 약점 | 최신 사실 | 지식 기준일 이후의 정보는 학습하지 않음 |
| 약점 | 드문 사실, 세부 정보 | 학습 데이터에 드문 정보를 그럴듯한 조합으로 채움(환각) |
| 약점 | 출처와 인용 제시 | 문헌을 검색하지 않고 서지 형식만 생성할 수 있음 |
| 약점 | 정확한 계산 | 숫자를 토큰 단위로 처리해 자릿수와 자리올림을 놓침 |
| 약점 | 긴 추론, 긴 입력 | 단계가 길수록 오류가 누적되고, 긴 입력의 중간 정보를 덜 활용 |
| 약점 | 사람에 대한 판단 | 학습 데이터의 편향을 결과에 반영 |

- 캡션 설명: `작업 유형별 강점과 약점, 작동 방식에서 비롯된 이유`
- 구분 열은 강점 6행, 약점 6행을 각각 `rowspan`으로 병합

- "생성형 AI의 한계와 대응" 절: 삭제. 표 1-5와 위 문단이 내용을 대신합니다.
