## 0. 사용자 지시
5장 첫 문단을 사용자 문안으로 바꿉니다. 사용자 문안:
> 생성형 AI는 학습과 연구 과정에서 개념 설명, 질문 답변, 연습 문제 출제, 요약, 자료 탐색 등을 지원하는 훌륭한 보조 도구입니다. 이때 사용자는 AI가 제공한 사실과 출처를 반드시 직접 교차 검증해야 합니다. AI의 역할은 '설명과 정리'에 국한되며, 이를 통한 '이해와 판단'은 온전히 인간의 영역이기 때문입니다. 이러한 역할 분담이 필요한 이유는 명확합니다. AI에게 학습의 전 과정을 의존하면 사용자에게 남는 지식이 없으며, AI가 범한 오류를 AI 스스로 검증하게 만들면 잘못된 정보가 그대로 고착화될 위험이 있기 때문입니다.

## 1. 반영 문장
사용자 문안의 내용(다섯 가지 도움, 직접 교차 검증, 설명과 정리는 AI, 이해와 판단은 사람, 두 가지 이유)을 모두 유지하고, 책의 문장 원칙에 맞춰 다듬었습니다.

**5장 첫 문단 전체 교체**
```
생성형 AI는 학습과 연구에서 개념 설명, 질문 답변, 연습 문제 출제, 요약, 자료 탐색을 돕는 보조 도구입니다. AI가 맡는 일은 설명과 정리이고, 그 내용을 이해하고 판단하는 일은 사람이 맡습니다. 그래서 AI가 제시한 사실과 출처는 사용자가 직접 교차 검증합니다. 학습을 AI에게 모두 맡기면 남는 지식이 없고, AI가 만든 오류를 같은 AI에게 확인하게 하면 오류가 그대로 굳어질 수 있기 때문입니다.
```

## 2. 사용자 문안에서 다듬은 점
| 사용자 문안 | 반영 | 이유 |
|---|---|---|
| 훌륭한 보조 도구 | 보조 도구 | 평가 표현(제품 분류 표와 같은 원칙, D-003) |
| 반드시 직접 교차 검증해야 합니다 | 사용자가 직접 교차 검증합니다 | "반드시"는 53차에서 정리한 단정 표현. 교차 검증의 뜻은 4장과 용어 풀이에 있어 그대로 사용 |
| 국한되며, 온전히 인간의 영역 | AI가 맡는 일은 설명과 정리이고, … 사람이 맡습니다 | 과장 표현과 문서투. 책 전체가 "인간" 대신 "사람"을 씀 |
| 순서: 검증 → 이유(역할) → 역할 분담 이유 | 역할 → 그래서 검증 → 이유 | 역할을 먼저 말해야 "그래서 직접 확인한다"가 자연스럽게 이어짐(한 문장 한 생각, 두괄식) |
| 이러한 역할 분담이 필요한 이유는 명확합니다. | 삭제 | 뒤 문장이 이유를 바로 말하므로 군더더기 |
| 'AI가 범한 오류', '고착화될 위험' | AI가 만든 오류, 그대로 굳어질 수 있기 | 쉬운 말로 |
| 작은따옴표('설명과 정리', '이해와 판단') | 삭제 | 강조 따옴표를 본문에 쓰지 않음 |

## 3. 그대로 두는 것
- 요점 상자 세 줄(답 대신 힌트와 질문, 참고문헌 원문 확인, 기관 규정 확인)
- 첫 문단의 "교차 검증"은 4장에서 정의한 뜻(원문과 서로 독립된 출처 두 곳 이상에 대조)과 같음. 5장은 4장 뒤라 별도 정의 없이 사용
