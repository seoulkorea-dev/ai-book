## 0. 사용자 지시
13차(67차)에서 반영한 5장 첫 문단을 사용자가 준 새 문안과 비교해, 두 문안을 합친 안으로 변경합니다(사용자 결정 "변경 필요").

새 문안(사용자 제공):
> 생성형 AI는 정보의 정리와 가공을 돕는 보조 도구일 뿐, 내용을 비판적으로 이해하고 판단하는 것은 인간의 역할입니다. 따라서 AI가 제시한 사실관계와 출처는 사용자가 논문이나 전문 서적을 통해 직접 교차 검증해야 합니다. 만약 정보 탐색과 분석을 AI에 완전히 의존하면 지식이 본인의 것으로 축적되지 않습니다. 또한, AI의 오류나 출처 조작을 같은 AI로 재검증하려 하면, 잘못된 정보가 걸러지지 않고 그대로 학술적 결함으로 고착될 위험이 있습니다.

## 1. 반영 문장(5장 첫 문단 전체 교체)
```
생성형 AI는 학습과 연구에서 개념 설명, 질문 답변, 연습 문제 출제, 요약, 자료 탐색을 돕는 보조 도구입니다. AI가 맡는 일은 정보를 정리하고 가공하는 것이고, 내용을 비판적으로 이해하고 판단하는 일은 사람이 맡습니다. 그래서 AI가 제시한 사실과 출처는 사용자가 논문이나 전문 서적 같은 원문으로 직접 교차 검증합니다. 정보 탐색과 분석을 AI에게 모두 맡기면 지식이 자기 것으로 쌓이지 않습니다. AI가 만든 오류나 지어낸 출처를 같은 AI로 다시 확인하면 잘못된 정보가 걸러지지 않고 그대로 남습니다.
```
문장 길이: 64, 61, 56, 43, 59자

## 2. 합친 방식
| 가져온 곳 | 내용 |
|---|---|
| 현재 문안(13차) | 장의 범위 목록(개념 설명, 질문 답변, 연습 문제 출제, 요약, 자료 탐색. 5장 절과 대응), 순서(역할 → 그래서 검증 → 이유) |
| 새 문안 | 확인 수단(논문이나 전문 서적 같은 원문), "비판적으로", "정보를 정리하고 가공", "정보 탐색과 분석", 출처를 같은 AI로 다시 확인하는 문제 |

## 3. 새 문안에서 쓰지 않은 표현과 이유
| 새 문안 | 이유 |
|---|---|
| 보조 도구일 뿐 | AI의 쓸모를 깎아내리는 말투로, AI를 학습에 잘 쓰는 방법을 다루는 5장과 결이 맞지 않음 |
| 인간의 역할 | 책 전체가 "사람"을 씀 |
| 출처 조작 | "조작"은 의도가 있다는 뜻. AI는 의도를 갖고 속이지 않으므로 "지어낸 출처"(1장, 4장 설명과 같음) |
| 학술적 결함으로 고착될 위험 | 연구에만 해당해 학습까지 다루는 5장 범위보다 좁음 |
| 만약, 또한 | 꼭 필요하지 않은 문장 첫머리 접속어(29차 원칙) |
| 사실관계, 축적되지 않습니다, 재검증 | 쉬운 말로(사실, 쌓이지 않습니다, 다시 확인) |
