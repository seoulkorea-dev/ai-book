### 4-2. 프롬프트 예제 말투 통일 (확정: "~해 줘")
**규칙(CLAUDE.md, STYLE.md 추가)**
- 코드 상자 속 프롬프트 예제는 모두 반말 요청체("~해 줘", "~하지 마")로 씁니다. 나쁜 예와 좋은 예의 말투를 같게 해, 차이가 조건에만 있게 합니다.
- 역할 문장은 "당신은 …입니다" 대신 "…의 관점에서 답해 줘", "…처럼 검토해 줘"로 씁니다.
- 본문, 표, 캡션은 지금처럼 합니다체입니다. 코드 상자 속 프롬프트만 해당합니다.
- 프롬프트가 아닌 코드 상자(Ch4 기록 예제, Ch8 AI 사용 표기 예제)는 바꾸지 않습니다.

**변환 기준**
| 현재 | 변환 |
|---|---|
| ~하십시오, ~해 주십시오 | ~해 줘 |
| 쓰십시오, 작성하십시오 | 써 줘, 작성해 줘 |
| 적으십시오, 표시하십시오 | 적어 줘, 표시해 줘 |
| ~하지 마십시오 | ~하지 마 |
| 나는 ~입니다, ~하려고 합니다 | 나는 ~야, ~하려고 해 |
| 당신은 ~입니다 | ~의 관점에서 ~해 줘 |

**lint(권장)**: check_style.py에 "코드 상자 안의 '십시오'" 경고 추가(변환 완료 커밋과 함께)

### 4-3. 2장 개선 전후 예제 교체 (15차 5-1 대체)

**개선 전**
```

```
**개선 후**
```
아래 공지문을 처음 읽는 사람도 바로 알 수 있게 정리해 줘.
읽는 사람은 일정, 해야 할 일, 기한을 가장 먼저 찾아.
항목, 내용, 기한 세 칸짜리 표로 만들고, 표 아래에 문의처를 한 줄로 적어 줘.
공지문에 없는 내용은 넣지 말고, 10줄 안으로 써 줘.

<공지문>
[3층 회의실 점검 안내]
10월 14일(화) 오전 9시부터 12시까지 전기 설비 점검으로 3층 회의실을 사용할 수 없습니다.

회의실에 둔 개인 물품은 10월 13일 오후 6시까지 치워 주십시오.
문의: 시설관리팀 내선 1234
</공지문>
```
- 공지문 원문의 "~주십시오"는 공지문 자체의 문체이므로 그대로 둡니다(프롬프트 말투 규칙 대상 아님).
- 문장과 구성 요소: 1줄 목적, 2줄 맥락, 3줄 출력 형식, 4줄 제약 조건, `<공지문>` 입력 자료. 역할은 이 작업에 필요하지 않아 쓰지 않습니다. 본문에 이미 있는 "모든 프롬프트에 다섯 요소가 필요하지는 않습니다"를 예제가 보여 줍니다.

**결과 예시(개선 후 프롬프트 바로 아래, 코드 상자 또는 표로 추가)**

|---|---|---|
| 회의실 사용 불가 | 전기 설비 점검으로 3층 회의실 사용 불가 | 10월 14일 9시~12시 |
| 회의 예약 변경 | 점검일 예약을 다른 날로 이동 | 10월 13일 |
| 개인 물품 정리 | 회의실에 둔 개인 물품 치우기 | 10월 13일 18시 |
문의: 시설관리팀 내선 1234
- 표로 넣으면 번호와 캡션 규칙이 적용됩니다(예: 표 2-n. 개선 후 프롬프트의 결과 예시 / 캡션 설명 1줄). 코드 상자로 넣으면 번호가 필요 없습니다. 작성 A가 정합니다.
