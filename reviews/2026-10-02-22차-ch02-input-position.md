# 2장 마지막 절(입력 자료 위치) 수정: 본문, 표 2-8, 그림 2-1의 배치 순서 통일

## 0. 배경
사용자가 2장 마지막 절 "입력 자료 위치"의 수정을 요청하고 문단 초안을 주었습니다. 검수 중 본문, 표, 그림이 서로 다른 순서를 말하고 있음을 확인했습니다.

## 1. 발견한 문제: 긴 자료의 배치 순서가 세 곳에서 다름
| 위치 | 현재 내용 | 뜻하는 순서 |
|---|---|---|
| 본문 | "긴 자료는 앞에 둔 뒤 목적과 출력 형식을 끝에 한 번 더 적습니다" | 자료 → 목적과 출력 형식. 그런데 앞에 지시가 없으므로 "한 번 더"가 성립하지 않음 |
| 표 2-8 | "자료를 앞에 두고, 목적과 출력 형식을 끝에 다시 적음" | 본문과 같음("다시"도 같은 문제) |
| 그림 2-1(긴 자료 쪽) | 구성 요소 → 긴 입력 자료 → 목적과 출력 형식 한 번 더 | 지시 → 자료 → 지시 반복 |
- 사용자 초안("긴 자료는 앞에 배치합니다. 다만 … 목적과 출력 형식을 끝에 한 번 더 강조")도 본문과 같은 모호함이 남습니다.
- 근거(1장, Liu 외 2023 「Lost in the Middle」): 긴 입력에서는 앞과 끝의 정보가 중간의 정보보다 잘 반영됩니다. 지시를 자료 앞뒤에 모두 두면 지시가 입력의 중간에 묻히지 않습니다. 그림 2-1의 순서(지시 → 자료 → 지시 반복)가 이 근거와 "한 번 더"를 모두 만족하므로, **그림에 맞춰 본문과 표를 고칩니다.**

## 2. 교체안
**본문(절 첫 문단 교체, 사용자 초안의 문장 흐름 반영)**
```
입력 자료는 길이를 기준으로 위치를 정합니다. 짧은 자료는 구성 요소 뒤, 프롬프트 끝에 배치합니다. 긴 자료는 구성 요소 다음에 배치하되, 자료 뒤에 목적과 출력 형식을 한 번 더 적습니다. 긴 입력에서는 앞과 끝의 정보가 중간의 정보보다 잘 반영되므로, 지시를 자료 앞뒤에 모두 두어야 지시가 입력의 중간에 묻히지 않기 때문입니다(Chapter 1). 그림 2-1에서 두 경우의 배치 순서를, 표 2-8에서 길이별 배치와 그 이유를 확인할 수 있습니다.
```
- 사용자 초안과 다른 점: "긴 자료는 앞에 배치합니다" → "구성 요소 다음에 배치하되"(그림과 일치), "반영률이 떨어지기 때문" → 1장의 근거를 그대로 풀어 씀("반영률"은 측정한 비율이 아니므로), "배치법" → "배치"

**표 2-8 긴 자료 행**
| 열 | 현재 | 변경 |
|---|---|---|
| 배치 | 자료를 앞에 두고, 목적과 출력 형식을 끝에 다시 적음 | 구성 요소 다음에 자료를 두고, 자료 뒤에 목적과 출력 형식을 다시 적음 |
| 이유 | 긴 입력의 중간에 놓인 지시는 덜 반영됨(Chapter 1 컨텍스트 윈도) | 긴 입력에서는 앞과 끝의 정보가 잘 반영되므로 지시를 자료 앞뒤에 둠(Chapter 1 컨텍스트 윈도) |
- 짧은 자료 행은 그대로

**그림 2-1**
- 순서는 그대로(구성 요소 → 긴 입력 자료 → 목적과 출력 형식 한 번 더)
- 긴 자료 쪽 아래 설명 "긴 입력의 중간에 놓인 지시는 덜 반영되므로 끝에 다시 적음" → `지시를 자료 앞뒤에 두어 중간에 묻히지 않게 함`(본문, 표와 같은 이유)

## 3. 반영 확인 기준

- 본문, 표 2-8, 그림 2-1이 같은 순서(구성 요소 → 긴 자료 → 목적과 출력 형식 다시)를 말함
- 그림 2-1 수정 뒤 화면 캡처로 확인(검수)
