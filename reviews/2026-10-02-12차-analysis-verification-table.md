# 6장 데이터 분석 기대 결과를 검증 요약 표로 교체

- 차수: 12차 (Claude), 누적 36차
- 이전 문서: 2026-10-02-11차-apply-check.md
- 기준 커밋: 43b037b

## 0. 배경
- 사용자가 6장 데이터 분석의 기대 결과 문단을 "검증 요약" 형식(합계 대조, 계산 오류, 변화 요인, 데이터 품질, 분리 대상)으로 바꾸자고 제안했습니다.
- 검수 쪽에서 사용자 안을 검토해 사실 오류 2건(단위, 오류 값의 출처)과 규칙 위반을 고친 수정안을 만들었고, 사용자가 수정안으로 반영을 지시했습니다.

## 1. 사용자 안에서 고친 점
| # | 사용자 안 | 수정 | 이유 |
|---|---|---|---|
| 1 | 1월 1,200만 원 … | 1,200(백만 원) | 표 6-4의 매출 단위는 백만 원(1,200 = 12억 원) |
| 2 | AI가 산출한 초안(−18.6%, 5.9)은 오류, PM이 재계산 | 파일 값 −18.6%, 5.9 / AI가 코드로 다시 계산한 값 −18.7%, 6.0 / 사람은 원본 작성 부서에 확인한 뒤 수정 | 오류 값은 원본 파일의 값이고, AI의 코드 재계산이 차이를 찾음(같은 절의 주장과 일치) |
| 3 | 협업 마케팅이 전체 성장을 주도함 | 같은 달 협업 진행(비고), 인과는 '추정' | 같은 절 프롬프트의 "원인은 '추정'으로 표시"와 일관 |
| 4 | [5.1] | 삭제 | 다른 답변에서 섞인 출처 표시 |
| 5 | 표 6-6(목록 형식) | 표 6-5(실제 표) | 번호를 붙이려면 표여야 하며 6-6은 기존 플랫폼 표 번호 |
| 6 | PM, 데이터 분석 PM | 사람, 분석 담당자 | 이 절은 묶음 2(업무 유형별 활용) |
| 7 | 패션/잡화, 디지털/가전, 3월과 4월 사이의 가운뎃점, 가채 집계, 환각 현상 차단, 속지 말고 | 패션잡화, 디지털가전, 3, 4월, 임시 집계, (삭제), 문체 정리 | 빗금과 가운뎃점 금지, 오기, 과장 표현, 구어 |

## 2. 교체안 (6장 데이터 분석 절)
**교체 대상**: "기대할 수 있는 결과의 예는 다음과 같습니다(AI의 실제 출력이 아님). 모든 행을 포함한 월별 합계는 … 추세 판단에서 따로 다룹니다." 문단 전체

**표 앞 문장**
```
아래 표는 이 프롬프트로 기대할 수 있는 결과를 검증 관점에서 정리한 예입니다(AI의 실제 출력이 아님).
```

**표 6-5. 데이터 분석 결과 검증 요약(예)**
| 검증 영역 | 대상 | 확인 결과 | 사람의 조치 |
|---|---|---|---|
| 합계 대조 | 월별 합계(모든 행) | 1월 1,200, 2월 1,080, 3월 1,350, 4월 1,320(백만 원). 행을 직접 합산한 값과 같음 | 확정 수치로 보고서에 사용 |
| 계산 대조 | 2월 자사몰 패션잡화 | 파일 값 −18.6%, 5.9만 원. 코드로 다시 계산한 값 −18.7%, 6.0만 원 | 원본 작성 부서에 확인한 뒤 다시 계산한 값으로 수정 |
| 변화 요인 | 3월 자사몰 패션잡화 +50.8% | 같은 달 인플루언서 협업 진행(비고). 표만으로 인과를 확인할 수 없어 '추정' | 협업 기간의 주문 자료로 효과 확인 |
| 데이터 품질 | 3월 오픈마켓 −36.2% | 연동 오류로 누락 의심 | 오픈마켓 판매 관리 화면의 자료로 실제 감소인지 재확인 |
| 분리 대상 | 3월 디지털가전, 4월 오픈마켓 | 시험 판매 데이터, 미복구로 인한 임시 집계 | 추세 판단에서 분리하고 보고서에 분리 사유 표시 |
- 캡션: `표 6-5. 데이터 분석 결과 검증 요약(예)` / `다시 계산한 값, 원인 추정, 데이터 품질 문제와 사람의 조치`
- 표 셀의 "디지털가전", "패션잡화", "임시 집계"는 표 6-4(가상 자료)의 표기와 같게 맞춤(표 6-4가 "임의 집계"로 되어 있으면 둘 다 "임시 집계"로 통일)

**표 뒤 문단(기존 "결과를 받은 뒤에는 합계 몇 개를 …" 문단 앞에 추가)**
```
AI가 정리한 결과 문장은 매끄러워도, 수치는 원본과 다시 대조하고 오류 의심 자료와 임시 집계는 판단에서 분리합니다. 계산은 AI가 맡더라도 어떤 자료를 결론에 사용할지는 사람이 정합니다.
```
- 기존 문단("결과를 받은 뒤에는 합계 몇 개를 원본 파일에서 직접 계산해 대조합니다. …")은 그대로 둡니다. 표의 "합계 대조"와 같은 내용이면 둘째 문장(표 계산 프로그램 수식 확인)만 남깁니다(작성 A 판단).
