### 4-2. 프롬프트 예제 형식이 genai-book과 같음 (수정 필요)
**근거**: genai-book 3장 "After(좋은 프롬프트)" 예제는 요소 이름을 대괄호로 달고 블록으로 나눈 형식입니다.
```
[Context] …
[Persona] …
[Task] …
[Constraints] …
[Format] …
```
이 책의 `[목적] [역할] [맥락] [출력 형식] [제약 조건]`은 같은 형식을 한국어로 옮긴 모양입니다. genai-book 부록 프롬프트 템플릿도 `[역할]`, `[형식]` 이름표를 씁니다. 문장이 달라도 겉모습이 같아 참고한 인상을 줍니다.

**검토한 대안**
| 대안 | 판정 | 이유 |
|---|---|---|
| 이름표를 `## 목적`(마크다운 제목)이나 `<목적>`(XML 태그)로 바꿈 | 비권장 | AI와 독자 모두 이해하지만, "요소마다 이름표를 단 블록" 구조가 그대로라 같은 형식으로 보임 |
| 사용자 제안 "고도화 최적안"(`<system_prompt>`, `<task_instructions>`) | 비권장 | ① 초안을 `<!-- -->` HTML 주석으로 써서 화면에 보이지 않음 ② 처리할 공지문이 없음 ③ 대화형 제품에서 사용자가 `<system_prompt>` 태그를 쓴다고 시스템 프롬프트가 되지 않아 Ch2 "프롬프트의 종류" 절과 충돌 ④ Ch2가 가르치는 구성 요소 틀, 표 2-1, 그림 2-1과 짝이 깨짐 ⑤ "가독성 분석 전문가"는 Ch2 "역할 부여" 절(역할은 전문 지식을 더하지 않음)과 반대로 읽힘 ⑥ "(To-Do)", "(Fact-based)" 불필요한 영문, "제출/이행" 빗금 |
| `<공지문>` 입력 자료 블록 삭제 | 비권장 | 처리할 자료가 없어져 프롬프트를 실행할 수 없음. Ch2 "구분 기호", "입력 자료 위치" 절과 그림 2-1의 입력 자료 칸이 이 블록을 예로 설명함. 자리표시 문구만 바꿈 |
| **요소 이름표를 없애고 문장으로 씀(권장)** | 권장 | 사용자가 실제로 입력하는 모양이며 genai-book과 겉모습이 다름. 요소 학습은 표 2-1과 그림 2-1이 맡음 |
