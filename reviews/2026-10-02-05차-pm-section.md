## 4. 사용자 지침 가운데 반영하지 않는 표현과 이유
| 표현 | 이유 |
|---|---|
| "작업의 순서와 배치를 최적화하는 알고리즘을 제공" | 대화형 AI는 일정 최적화 알고리즘을 실행하지 않고 순서를 제안합니다. 현재 원고("AI에는 순서와 배치를 맡김")가 정확함 |
| "실시간 데이터를 취합하여 … 자동 생성" | 연결된 도구(MCP 등)가 있을 때만 가능합니다. 이 절의 예제는 사람이 기록을 입력하는 방식이라 맞지 않음 |
| "수많은 프로젝트 데이터를 기반으로 흔한 위험을 누락 없이" | 학습 데이터의 내용은 확인할 수 없고, "누락 없이"는 1장(강점과 약점), 4장(환각)의 설명과 어긋남. "흔한 위험을 빠르게 나열"(현재 원고)로 유지 |
| "AI를 강력한 비서로" | 평가 표현. "초안을 빠르게 만드는 도구"로 |
| "맹신", "쪼개놓은", "녹여내어" | 어휘 치환과 문체 규칙(사용, 나누다, 반영하다)으로 바꿈 |
| 영문 병기(Stakeholders, Scope, Estimation, Buffer, Blind Spot, Decision Making) | 병기 원칙(용어 풀이 표제어의 장별 첫 등장)에 해당하지 않아 한국어만 씀 |
| "PM" | 사용자 결정: 약어 없이 `프로젝트 매니저`로 씀. 본문의 "프로젝트 관리자", "프로젝트 책임자"도 모두 "프로젝트 매니저"로 통일 |
