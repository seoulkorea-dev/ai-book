# 표
PLAYBOOK 8장(표)과 10.1(캡션)을 따릅니다.
- 표를 만들기 전에 PLAYBOOK 8.2의 표준 세트에서 하나를 고릅니다. 맞는 세트가 없으면 간단한 표(열 2~3개, 행 2~5개)로 쓰고, 실패 표와 확인 표 대신 쓰지 않습니다.
- 열은 명사형 2~4개입니다. 범위가 넓은 열 이름, 동사형과 질문형 열 이름, 본문 연계 열, 지시 표현을 쓰지 않습니다.
- 행은 모두 같은 질문의 답이고 3~7개입니다. 칸은 명사형 한 내용이고 마침표를 찍지 않습니다. 칸에 문장이 둘 이상이면 본문으로 옮깁니다.
- 예제 적용 표의 값은 예제 사실 문서와 글자까지 같게 씁니다. 캡션과 표 앞 문장의 개수는 실제 행 수와 같아야 합니다.
- 캡션은 "표 N-n. 제목"(명사구), 근거 괄호 없음. 표 앞 문장은 표의 핵심 한두 가지를 먼저 말합니다.
