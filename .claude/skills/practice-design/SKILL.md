# 실습
PLAYBOOK 11.2(실습), 11.3(코드, 설정, 명령)을 따릅니다.
- 순서: 준비물 → 따라 하기(입력할 곳과 명령) → 실행 결과(실제 출력) → 확인 방법 → 막혔을 때.
- 실행 폴더, 입력할 곳, 파일을 만들 곳, 같은 파일이 이미 있을 때의 처리, 처음 실행할 때의 설치와 로그인, 운영체제별 차이를 적습니다.
- 명령마다 무엇을 하는지와 결과를 그 자리에 적습니다. 실패(오류, 종료 코드)일 때 할 일과 처음 상태로 되돌리는 방법을 적습니다.
- 실행 결과에는 실제로 실행한 출력만 씁니다. 실행 기록이 없으면 "실행 기록 확인 전의 예상"으로 표기하고 temp/docs/AUTHOR_QUEUE.md에 "출간 전 실행"으로 적습니다.
- 코드와 설정은 각 부분의 뜻을 앞뒤 문장으로 풀고, 발췌는 발췌임과 더할 위치를 밝힙니다. 참고본 파일 이름에는 .example을 붙입니다.
