# 사실과 인용
PLAYBOOK 6장(사실과 인용), 7장(주장의 범위와 책임 구분)을 따릅니다.
- 원문으로 확인한 사실만 씁니다. 쓰기 전에 책 저장소 research/<장>-sources.md에 출처, 확인 날짜, 원문 문장을 남깁니다. 열지 못한 사실은 문장을 바꾸지 않고 temp/docs/AUTHOR_QUEUE.md에 "출간 전 확인"으로 적습니다.
- 본문의 명령은 실제로 실행해 출력으로 확인한 뒤 씁니다. 제품 동작은 한계(막지 못하는 경로, 기본값)까지 씁니다.
- 제품 동작은 원문의 동사와 주체를 그대로 두고, 문장 구조는 한국어로 새로 씁니다. 출처는 문장 끝 인용 번호로 밝히고 주어로 세우지 않습니다.
- 장을 다시 짜거나 문단 셋 이상을 고친 뒤에는 고치기 전과 후의 숫자, 영문 고유명사, 인용 수를 대조합니다.
- 원칙, 예제의 선택, 제품의 동작을 한 문장에 섞지 않습니다. 인용 표기는 PLAYBOOK 6.4(문장 끝 위첨자, 책 끝 참고 문헌)를 따릅니다.
