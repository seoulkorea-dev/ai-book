# 예제
PLAYBOOK 11.1(예제)을 따릅니다. 예제 이름과 사실 문서의 위치는 BOOK_SPEC의 예제 절에 있습니다.
- 예제 하나를 책 전체에서 같은 이름으로 씁니다. 장마다 첫 등장은 정식 이름, 이후 짧은 이름입니다.
- 예제 사실은 예제 사실 문서 한 곳에 두고, 본문, 표, 실습 파일이 글자까지 같게 따릅니다. 바꾸면 같은 작업에서 모든 곳을 고칩니다.
- 예제 값은 예제 절에만 두고, 원리 절의 예는 독자가 아는 일로 듭니다. 그림에는 예제를 넣지 않습니다.
- 완료 기준의 확인 방법은 구현 전에는 실패하고 구현 뒤에는 통과해야 합니다. archive/<책>/tools/check_tasks.py가 있으면 check_all의 "예제" 단계가 이를 검사합니다.
- 실행하지 않은 결과는 "예상 결과"로 표기합니다. 계산은 코드로, 날짜와 요일은 달력으로 검산합니다.
