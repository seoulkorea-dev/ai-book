# 장과 절의 구조
PLAYBOOK 2장(장 구성), 3장(절과 문단), 10.2(링크와 참조)를 따릅니다. 견본 장은 BOOK_SPEC의 "견본 장"입니다.
- 장 틀: 주장 줄 → 도입부(문단 1, 2, 3과 요약) → 원리 절 → 예제 절 → 실패를 예방하는 장치(항목마다 "비었을 때 생기는 일"을 다루면 두지 않음) → 설정과 결과의 확인 방법 → 설계 원칙과 점검 질문. 예외는 BOOK_SPEC의 장 틀 예외만.
- 주장 줄은 관계나 조건을 서술하는 한 문장이고 site.json desc와 같은 문장입니다. 한쪽을 고치면 같은 작업에서 다른 쪽도 고칩니다.
- 원리 절의 예는 독자가 아는 일로 들고, 예제 값은 예제 절에만 둡니다. 항목의 예외와 한계는 절 끝 한계 문단 하나에 모읍니다.
- 문단은 쓰기 전에 "이 문단의 한 가지"를 한 줄로 적고, 왜 → 언제 → 어떻게 → 그래서 순서로 놓습니다. 세부는 PLAYBOOK 3.1의 4가 정한 네 자리로 옮깁니다.
- 절 제목은 명사구나 "~하기"로 씁니다. 절 끝에는 다음 절의 물음을 꺼내는 연결 문장 하나만 둘 수 있습니다.
- 다른 장 링크는 이 장에서 한두 문장으로 설명한 뒤 내용이 있는 절에 겁니다. 같은 장 링크와 가리키기만 하는 문장은 쓰지 않습니다.
