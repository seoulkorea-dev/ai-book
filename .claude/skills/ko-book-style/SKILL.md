# 한국어 기술서 문체(요약, 기준은 NEW_BOOK_PLAYBOOK.md 6장과 BOOK_SPEC.md)
- 본문은 쉬운 말 합니다체. 항목 나열은 가운뎃점 대신 쉼표. 한 문장에 한 생각, 150자 넘으면 나눈다.
- 절 첫 문장은 정의나 결론. 추측 표현과 lint/banned.txt의 금칙어는 쓰지 않는다.
- 어휘: 쓰다 → 사용하다, 작성하다 / 바꾸다 → 변경하다, 변환하다 / 고르다 → 선택하다 / 넣다 → 입력하다, 포함하다 / 붙이다 → 첨부하다, 추가하다 / 고치다 → 수정하다 / 끄다 → 해제하다(인용문, 일부러 보인 나쁜 예, 고유명사, 법령 조문은 예외).
- 영문 병기: 장마다 용어 풀이 표제어가 처음 나올 때 `한글(원어)`, 표 칸, 캡션, 제목, 코드 상자에는 병기하지 않는다.
- "이 책" 표현, 독자 언급, 1인칭, 프롬프트 예제 말투, 예제의 인물 지칭은 BOOK_SPEC.md의 표기 절을 따른다.
- 확인: python tools/check_all.py(문체, 금칙어).
